# 발자국 코드·Supabase 점검 — 2026-10-19

## 확인 범위

- GitHub main 최신 커밋과 배포 상태, 추적된 애플리케이션 파일 739개의 service-role JWT 노출 여부.
- Supabase 발자국 프로젝트(euwujrpjtwsrxhiytego)의 상태, public 테이블 18개의 RLS, 공개 뷰, 함수 실행 권한, 주요 관리자·포인트·알림·탈퇴 함수, Storage 정책.
- 로그인, 계정 전환, 관리자 로딩, 가입 포인트, 탈퇴, 찜, 지도 검색, 산책 기록, 동반 조건·사진 권리, 검색 페이지 및 배포 경계를 다루는 자동 검사.

## 수정

1. 배지 및 관리자 권한 조회에 요청 번호와 요청 당시 계정 검사를 추가했다. 계정 변경·로그아웃·동일 계정의 중복 요청에서 오래된 성공/실패 응답이 최신 화면을 덮어쓰지 않는다. 비회원 상태에서 관리자 목록을 불필요하게 요청하지 않는다.
2. Windows CRLF로 인해 탈퇴 검사가 import 문을 제거하지 못했던 오류, GPX 원문 해시의 줄바꿈 차이, 경로 JSON 추출 오류를 수정했다. 분리된 관리자 번들과 현재 검색 상태를 검사하도록 오래된 검사 위치를 수정했다. 실제 좌표·해시·권한 검증은 보존했다.
3. Supabase에서 public 테이블의 불필요한 TRUNCATE/REFERENCES/TRIGGER 권한과 포인트·홍보권 직접 INSERT/UPDATE 권한을 회수했다. 알림 직접 INSERT 제한을 재확인하고 사용하지 않는 과거 INSERT 정책을 제거했다. 기존 RLS가 쓰기를 거부하던 경로의 방어를 추가한 것으로, 해당 권한이 REST에서 악용됐다고 판단한 것은 아니다.
4. 제휴 정보 권한 정책 2개에서 auth.uid()를 SELECT로 감싸고 이벤트 prize_slots.current_campaign 인덱스를 추가했다. 성능 advisor의 초기 경고 2개와 외래키 인덱스 누락 1개가 사라졌다.
5. GitHub push/PR에서 전체 애플리케이션 검사를 자동 실행하도록 읽기 전용 워크플로를 추가했다.

## 검증

- 전체 자동 검사: 112개 통과, 실패 0개. 추가로 기존 미추적 offline-shell 검사 통과(기존 미추적 파일은 커밋하지 않음).
- 인라인 JavaScript 8개와 서비스워커 구문 검사 통과.
- Supabase tests/client_grants.sql: 트랜잭션 내 권한·RLS·공개 뷰 검사, 임의의 비관리자 계정 문맥에서 다른 계정의 산책/포인트/알림 조회 불가 및 관리자 포인트 조정 거부 확인 후 rollback. 회원·활동 데이터 수정 없음.
- 포인트 RPC 실행, 관리자 포인트 삭제 권한, 비회원 코스 조회 권한 유지 확인.
- 공개 뷰 traffic_clean_page_views는 security_invoker=true이며 비회원 직접 조회 불가.
- 공개 코드에서 service-role JWT 발견 0건. 정상 공개 anon 키를 비밀 키로 오인해 제거하지 않았다.

## 남은 사항과 한계

- Free 요금제임을 현재 조직 정보에서 확인했다. 유출 비밀번호 차단은 Supabase 공식 문서상 Pro 이상 기능이므로 유료 전환하거나 설정을 변경하지 않았다. 현재 제공하는 로그인 UI는 카카오·구글·이메일 링크 방식이다.
- 집계용 공개 함수 및 로그인 회원용 포인트 RPC의 SECURITY DEFINER 경고는 의도된 API 설계다. 인증·관리자 검사와 제한된 결과/작업을 확인했으며 기능을 끊는 일괄 실행권한 회수는 하지 않았다. 비공개 테이블의 RLS 정책 없음은 직접 접근을 막는 상태다.
- 미사용 인덱스 INFO는 삭제하지 않았다. 신규 인덱스도 아직 사용 통계가 없을 수 있다.
- 최근 로그 소스별 집계 조회는 성공했지만 상세 로그 조회는 Supabase 연결 오류로 실패했다. 따라서 최근 모든 서버 오류가 없다고 판단하지 않았다.
- 이번 점검은 발견된 문제의 수정과 회귀 검증이며 모든 잠재 오류 부재를 보증하지 않는다. 실제 기기 화면 잠금·백그라운드 GPS와 실제 계정 삭제/이벤트 추첨은 실행하지 않았다.
