## 🗄️ database_sql 폴더
지금까지 만들어드린 데이터베이스 변경 이력 전부예요 (v3 ~ v21).

**대부분은 이미 Supabase에 적용하셨을 거예요.** 이 폴더는 "전체 기록 백업" 용도로 드리는 거라, 새로 적용하실 필요는 없어요.

혹시 **Supabase 프로젝트를 새로 만들거나, 적용 여부가 헷갈리시면** — v3부터 순서대로 하나씩 실행하시면 안전해요 (뒤 번호가 앞 번호를 전제로 만들어져 있어요).

**가장 최근에 만들어드린 것 (혹시 아직 안 하셨다면 꼭 확인해주세요)**
- `schema_v20_approval_system.sql` — 코스/배변봉투함/동반시설 등록 시 관리자 승인 필요하도록 하는 기능
- `schema_v21_pageviews_read_fix.sql` — 방문자 수·페이지뷰가 0으로 뜨던 문제 수정
- `schema_v22_security_hardening.sql` — GPS 산책 경로·실시간 위치·방문 통계·포인트 내역의 공개 조회를 차단하고 업로드/알림 권한을 강화하는 필수 보안 패치

> 기존 프로젝트라면 v22만 추가 실행하면 됩니다. v22 적용 후 공개 화면의 “지금 산책 중” 숫자는 위치 원본 대신 코스별 집계 뷰에서 불러옵니다.
