# 반려견 동반 산책로 경로 검토

이전 배포에서 위치만 안내했던 22곳을 재검토해 16곳에 공개 지도에서 확인한 연결 보행 구간을 추가했다. 이 구간은 발자국이 자료로 대조한 제안 경로다. 상세와 지도에 점선, 거리, 시작·끝 지점 및 지도 출처를 표시한다. 출입 가능 근거는 이전 운영기관 자료를 사용하고, 구역별 제한을 유지했다. 울산 대왕암공원 출렁다리는 다리 구간과 이동장 조건을 표시하며, 곽지해변은 연결이 확인된 육상 구간만 안내한다.

신규 3곳은 제주 표선·삼양해변과 섭지코지다. 제주관광공사 또는 한국관광공사 동반 안내, 연결된 공개 보행로, 같은 장소에서 촬영한 공공누리 제1·3유형 사진을 각각 대조했다. 공개 코스 수는 526곳에서 529곳으로 갱신된다. 사진별 출처와 제3유형 원본을 보존했다.

보행 경로가 남은 6곳의 근거와 제외 사유는 `batch.json`에 기록했다. 현장 통제·제한 구역, 어시장 작업 구역, 지도상 장소 구분, 기존 코스와 겹치는 구간을 확인해 대표 위치 안내로 유지했다. 지도상 거리와 통행 상태를 구분하며 현장 답사는 하지 않았다.
