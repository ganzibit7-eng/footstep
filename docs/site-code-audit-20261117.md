## 확인하고 수정한 문제

- 공유 페이지 `/share/`의 산책 카드가 운영에서 HTTP 404를 반환하는 계단 없는 코스 목록을 가리켰다. 현재 공개 목록인 2km 이하의 쉬운 코스와 연결하고 카드 문구를 목적지와 일치시켰다. 계단이 없다는 안내는 실제로 보장할 수 없어 제거했다.
- CSV 처리 라이브러리 로드가 관리자 초기 진입의 필수 조건이었다. 실제 CSV를 선택할 때만 불러오도록 바꿨다. 라이브러리 재시도는 관리자 대시보드와 독립적으로 작동한다.
- CSV 컬럼 이름을 HTML 문자열에 연결하던 출력을 텍스트 노드로 변경했다. 다른 파일을 선택했거나 관리자 세션이 바뀐 뒤에는 이전 파일의 파싱 결과로 화면이 갱신되지 않는다.
