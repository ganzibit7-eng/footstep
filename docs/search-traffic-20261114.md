Google 웹 검색 11월 5~11일 클릭 2회·노출 3회, 직전 10월 29일~11월 4일 클릭 0회·노출 1회. 28일 기준 클릭 13회·노출 806회 중 10월 15일 노출이 459회였다. 색인 보고서 11월 9일 갱신본에서 색인 440개, 발견 후 미색인 20,619개, 수집 후 미색인 2,606개, 서버 5xx 0개. sitemap.xml은 11월 13일 읽기 성공. 대표 산책코스 하나는 모바일 Googlebot의 가져오기, 색인 허용과 사이트가 선언한 대표 주소가 정상인 상태에서 미색인이었다. 색인 하락의 전체 원인은 확정할 수 없으며 네이버 주간 감소의 직접 원인으로 연결하지 않는다.

## 이번 변경

- 최근 유입 감소 및 네이버 접근 불가 표본에서 확인한 옛 장소 주소 15개에 동일 지역의 공개 목록 링크를 제공한다. 지역 내 해당 업종 목록이 있을 때만 별도 버튼을 표시한다. 알 수 없는 주소는 기존 공통 링크만 표시한다. HTTP 404, noindex, 공개 보류 및 기존 URL 유지.
- 네이버 유입에 감소가 확인됐으며 현재도 정상 응답하는 제주 광역 코스 목록에 산책 비교를 추가한다. 지도에 제공되는 송악산·닭머르 공식 GPX와 쇠소깍 공개 보행로 기반 제안 구간에 연결한다. 기존 생성기로 재생성할 때 제목, 설명, 비교 영역을 유지한다.
- 홈페이지와 방문자 집계 로직은 그대로 사용한다. 실적은 마감된 같은 요일의 7일 구간으로 다시 비교하고 네이버 유입·활동 확인·직접/출처 미상을 별도로 본다. 색인 요청과 실제 노출 회복은 구분한다.
