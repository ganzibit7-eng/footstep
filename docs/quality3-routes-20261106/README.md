## 실제 문제와 수정
- c352의 GPX 측정5.04km와 기존 소개의 공식 전체6.5km가 떨어져 있었다. 원문의 공식 전체 숫자가 하나로 식별될 때만 핵심 영역에 함께 표시한다. 중복 등록 참고5.04km는 좌표와 함께 펼치기로 보존한다. 차이를 오류/부분 제공으로 확정하지 않는다.
- 좌표가 지도보다 먼저 노출됐던55개 GPX 상세의 좌표를 하단 접기 영역으로 이동. 출처/JSON/좌표/SEO/사진/라이선스 보존. c133은 미확인 상태 및 GPX없음 그대로.
- 기존 SDK 재시도는 CSS 오류를 기다리지 않아 스타일 누락을 성공으로 처리할 수 있었다. JS/CSS를 함께 기다리고 실패/시간 초과 시 둘 다 정리·재시도. 지도 버튼을 수동 조작 중이면 성공 후 전체보기 버튼으로 포커스 전달.
- 출발·도착 표식에 별도 클래스/색상과 기존 S/E 문자 유지. 구간을 연결하거나 가짜 경유지를 만들지 않음.
- 공통 routeAssets/routeClarity에 적용,55개 현재 페이지와 재생성 idempotence 검사. 홈은 변경하지 않고 SW v242-route-clarity 갱신.
