# 후속 동반 안내와 사진 보강 — 2026-10-20

이전 대조의 나머지 캠핑장 406곳을 상호·주소가 일치하는 고캠핑 공식 공개 페이지와 대조했다. 61곳에서 반려동물 관련 소개를 찾았고 기존 조건의 단순 반복을 제외해 19곳에 추가 참고 안내를 보강했다. 용두산오토캠핑장은 기본 소형견 허용 표기와 소개의 동반 불가 문장이 달라 재확인 경고를 추가했다. 현재 허용·금지를 확정하지 않는다.

가평명지산카라반글램핑은 10kg 미만 소형견·객실당 최대 2마리·마리당 3만원·지정 객실만·사전 연락·상황별 매너벨트·외부 목줄·생리 중 기저귀 조건을 함께 보존한다. 정확한 객실 번호와 현재 요금은 문의하도록 안내한다. 대형견 입마개 권유를 의무로 바꾸지 않는다. 수정일이 오래된 대형견 허용·전 객실 허용 표현은 현재 확정 필터로 승격하지 않는다. 소개 참고에 원문 수정일과 대조일을 구분해 표시하고 기존 동반 정보의 확인일은 유지한다.

사진이 없던 가지산도립공원(밀양)에 Commons 원문이 가지산도립공원 경관으로 설명하는 공개 라이선스 사진 1장(265,564바이트)을 추가했다. 공원 권역 경관이며 개별 방문 지점·전체 경로 사진이 아니라고 명시한다. 나머지 후보 1장은 전경 인물 때문에 제외했다. 제공 축소본의 전체 비율·바이트를 유지하고 출처·저작자·촬영 정보·파일 제목·개별 라이선스·원문 스냅샷을 보존했다.

전체 사진 보유 1,222곳·4,092장, 사진 미보유 1,911곳이다. 사진 사용 허락을 확인하지 못한 장소는 임의 사진으로 채우지 않았다. 새 구조화 동반 조건·DB 허용 값을 만들지 않았으며 회원·로그인·GPS 데이터와 Cloudflare 권한은 변경하지 않았다.

홈 등록 수는 방문자 접속 때 재집계하지 않는 배포값으로 바꿨다. 현재 실제 등록 수 407개·3,133곳은 그대로다. 사진·소개 보강은 새 장소 등록으로 집계하지 않는다. 수동 갱신 도구와 지침은 docs/public-counts.md 참조.

공식 출처는 selected-notes.json.gz의 고캠핑 개별 페이지와 selected-photos.json.gz의 Commons 파일 원문이다. 조회 요청에는 문의 이메일을 포함하지 않는다. 상업적 재사용을 확인하지 못한 고캠핑 웹 사진은 사용하지 않았다.
