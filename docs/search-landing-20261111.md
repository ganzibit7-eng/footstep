# 검색으로 방문하는 코스와 옛 링크 안내 개선

운영 통계에서 조회가 확인된 청계산 원터골, 안산자락길, 남산공원, 인왕산 숲길의 검색 제목과 설명을 개선했다. 서울시 원문에서 확인한 대중교통 출발 위치와 코스 이용 조건을 상세에 추가하고, 같은 기준을 정적 페이지 생성기에 적용했다. 기존 코스 URL, 원문, 사진, 지도는 그대로 사용한다.

검색에 남아 있는 이전 장소 주소에서 현재 공개 목록으로 이동할 수 있도록 GitHub Pages의 404 안내를 추가했다. 404 상태와 검색 색인 제외를 유지한다. 비공개 장소를 복원하거나 다른 주소로 자동 이동시키지 않는다.

배포 후 대상 코스 네 곳의 응답과 검색 제목, 옛 장소 URL의 404 상태와 안내 문구를 확인한다. 배포 전후 네이버 노출·클릭과 방문 브라우저 변화를 같은 요일로 비교한다.
