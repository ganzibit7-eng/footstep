# 지도 화면 정돈 — 2026-10-19

기존 발자국 지도·검색·분류·동반 조건·사진 출처를 유지하며 지도 화면만 정돈했다.

- 검색 입력에 보이는 레이블을 연결하고 글자·간격·지우기 버튼 정렬을 조정했다.
- PC의 검색 패널과 지도를 유지하고, 모바일의 네 분류 버튼은 44px 이상 높이로 유지했다.
- 클러스터 숫자를 초록/흰색으로 통일하고 지도 타일의 채도를 낮췄다. 지도 제공처와 저작자 표시는 보존했다.
- 시설 마커는 고정 SVG 선 아이콘으로 바꾸고 실제 장소 이름을 title/alt에 지정했다. 외부 일반 장소의 동반 미확인 안내는 유지했다.
- 팝업과 코스 요약 카드의 글자·구분선·버튼을 정리했다. 사진 출처와 전체 비율 표시는 보존했다.
- 등록 장소의 종류·이름 필터와 초기화 버튼을 정리했다. 필터링·검색 취소·등록 정보 우선 표시 로직은 변경하지 않았다.
- CSS는 map-section에 한정하고 서비스워커 셸 버전을 갱신했다. 로그인·회원정보·GPS·데이터베이스 설정은 변경하지 않았다.

검증: 기존 지도 검색 및 등록 장소 필터 검사, 홈 첫 화면 검사 통과. 인라인 스크립트 8개와 서비스워커 구문 검사 통과. 배포 용량·사진 요청 한도·검색 페이지 검사 15개 통과. 브라우저에서 390px·360px 모바일 및 PC 배치를 확인했고 작은 화면의 가로 넘침이 없고 분류 버튼 높이가 44px임을 측정했다. 로컬 미리보기의 일반 장소 외부 검색은 서비스 연결 실패 안내로 대체됐으며 등록 검색 결과는 정상 유지됐다. 운영 도메인에서는 별도로 확인한다.
