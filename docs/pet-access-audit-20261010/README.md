공식 경로 존재와 반려견 동반 허용을 분리해 검토했다. 승인 상태였던 미확인 468개를 pending으로 보존했다. 나머지 223개의 190개 고유 출처를 다시 조회했다. 서울시 개별 코스의 반려견 출입 가능 문구와 한국관광공사 공개 상태·동반구분·견종·제한 조건을 보존했다. 201개는 명시적 전체 동반 안내가 확인되었다. 일부구역인 6개는 기존 원본 경로 및 제한시설 제외 자료와 현재 야외 산책 허용 또는 해당 코스에 대한 공식 반려동물 여행 안내를 함께 대조했다.
