# 관리자 보안 알림 정리 · 2026-10-18

원인: script-src 위반을 맥락 없이 script_policy_block으로 전부 warning 기록하고, 10분에 5건이면 브라우저 보고만으로 관리자에게 알렸다. 최근 7일간 브라우저 정책 차단 599건, 서버 invalid_session 1건이 있었으며, 정책 차단 대상·원인은 기존 기록에 없어 공격 여부를 확정할 수 없다.

- CSP 보호 정책은 유지. 보고 수집과 알림 판정만 정리.
- 일반 CSP·브라우저 로그인 실패/제한은 신규 저장 제외. 구버전 클라이언트 보고도 Edge와 DB에서 무시.
- 강제 적용된 스크립트 차단 중 문서·발신 소스가 사이트이고 허용 목록 밖 HTTP(S) 외부 출처인 경우만 external_script_block 참고 신호로 기록. report-only·확장 기능·inline/eval·출처 미상·허용 제공자 차단은 공격으로 판단하지 않음.
- Edge에서 출처·지시자·전송 범위 재검증. 원본 차단 URL·검색어·토큰은 전송하지 않고 출처만 전송하며 DB에는 사건 종류와 사이트 경로만 저장. 브라우저 보고는 여전히 위조 가능하므로 공격 확정·자동 알림 근거로 삼지 않음.
- 관리자 알림: 서버 확인 admin_access_denied / submission_guard / account_delete_failed만. 30분 중복 제한 유지. 세션 만료·일반 처리 결과는 운영 감사 info로 유지하되 기본 보안 패널에서 제외.
- 기존 일반 CSP 알림은 읽음 처리하고 원본 사건·메시지는 삭제하지 않음. 원래 30일 사건 보관 기준 유지.
- 관리자 전용 변경이므로 홈 업데이트 공지는 추가하지 않음.

검증: 브라우저 보고 분류·URL 최소화·조작된 출처·구버전 보고 억제·서버 사건 위조 거절·알림·권한·오프라인 캐시 검사. 운영 DB 테스트는 트랜잭션을 롤백해 허위 알림·사건이 남지 않게 함.

한계: 이 필터가 ‘실제 공격만 100% 탐지’한다는 뜻은 아니다. 기존 599건의 차단된 스크립트 원인을 복구하거나 안전을 확정하지 않았으며 서버·인프라 로그 확인을 대체하지 않는다.
