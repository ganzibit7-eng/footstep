# 전국 동반 장소 추가 대조 — 2026-10-20 두 번째 묶음

이전 묶음과 별개로 3672곳·409개를 기준으로 대조했습니다.

- 공식 동반 구조화 항목 조사 32700/32700건. 확인되지 않거나 상충하는 자료·사진 권리가 없는 항목은 미공개.
- 신규 장소 363곳, 상업 재사용이 허용된 개별 공식 사진 363장. 334곳은 구조화 동반 조건, 29곳은 현재 공식 소개의 동반 근거를 보존합니다.
- 구체적인 조건이 없는 항목은 미확인. 소개의 일부 구역·객실 허용을 전 시설 허용으로 확대하지 않습니다. 확인 날짜는 현장 답사일·운영정책 갱신일이 아닙니다.
- Type1/Type3 사진만 사용. 원본 파일의 해시·크기·비율과 개별 권리 응답을 보존하고 잘라내거나 편집하지 않았습니다.
- 신규 제안 경로 3개: 경계 안 원본 보행로만 사용하며 실제 경로 증명과 기존 409개 경로와의 중첩 검토는 route-proof.json에 있습니다. 현장 답사·공식 지정 코스가 아닙니다.
- manifest의 pending은 검토 시점 상태입니다. DB 공개는 해당 ID와 설명 해시가 일치할 때만 별도 트랜잭션으로 수행합니다. 기존 공개 행·회원정보·인증·권한 설정을 변경하지 않습니다.
- 홈 숫자는 실제 공개 승인 이후 수동 갱신합니다. 방문자 집계 요청은 추가하지 않습니다.

공식 출처: 한국관광공사 관광정보 허브(https://api.visitkorea.or.kr/), 개별 장소·사진 응답과 공공데이터 이용허락(https://www.data.go.kr/data/15101578/openapi.do). 경로 원본은 OpenStreetMap/Geofabrik, ODbL 1.0.
