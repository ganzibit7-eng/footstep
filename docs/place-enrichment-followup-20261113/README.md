# 신규 장소 사진·동반 조건 후속 확인

2026년 11월 13일, 383곳 등록 묶음 중 이전에 사진을 확보했거나 보류한 장소를 제외한 공개 장소 369곳을 대상으로 재조사했다.

- 공공누리에서 369곳을 상호로 조회하고, 검색된 이미지 자료를 상호·소재지와 대조했다. 동명 업체, 인접 장소 및 비상업 조건이 붙은 사진은 게시하지 않았다.
- 한국관광공사의 국문·영문·일문·중문 자료 110,438개를 장소명, 주소, 좌표와 비교했다. 남양주 스타벅스 더북한강R점과 일치한 영문 관광 자료에서 공공누리 제3유형을 확인한 사진 3장을 선택했다. JPEG 파일을 그대로 제공하며 사진별 출처와 허락 조건을 표시한다.
- 운영사 공식 사이트, 공단 이용 수칙, 고캠핑에서 연결한 예약 안내 등으로 9곳의 동반 조건을 보강했다. 스타벅스 더북한강R점은 1층 실내 펫존·야외 펫파크, 태백 고원힐링캠핑장은 15kg 및 체고 40cm 이하, 강릉 하슬라 캠핑장은 허용 구역에서 10kg 미만 기준을 안내한다. 확인되지 않은 체중·시설 출입 기준은 미확인으로 표시한다.
- 논산 숩쏙캠핑장과 울주 화장산 캠핑장은 현재 운영사 예약 안내가 반려동물 동반을 명시적으로 금지한다. 기존 등록 데이터는 보존하고 공개 승인을 보류했다. 공개 승인 동반장소는 4,147곳, 전문업소를 포함한 전체 반려생활 장소는 21,844곳이다.

업체가 게시한 사진은 해당 업체가 발자국에 게시를 허용한 근거를 확인한 경우에만 사용할 수 있다. 신세계그룹 뉴스룸의 사진은 비영리·개인 용도로 한정돼 이번 반영에서는 사용하지 않았다.
