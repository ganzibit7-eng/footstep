1. 회원 정보와 처리 목적

필수 회원 정보는 인증 계정 식별자·이메일 및 로그인 제공자가 이용자의 동의 범위에서 전달하는 이름·프로필 사진입니다. 로그인·회원 식별·계정 관리에 이용하며 가입 시 수집·이용 동의를 받습니다. 동의를 거부할 수 있으나 회원 기능은 이용할 수 없습니다. 공개 코스 열람은 회원가입 없이 가능합니다.

닉네임은 공개 작성자 표시와 회원 기능에 사용합니다. 등록 지역과 반려견 이름·견종·나이·사진은 선택 입력이며 지역 추천과 프로필 기능에 사용합니다. 프로필 수정으로 정정·삭제할 수 있습니다. 로그인 제공자의 정보 전달 범위는 해당 로그인 화면에서 확인합니다.

만 14세 이상만 가입을 허용합니다. 로그인 전 연령 확인란에 직접 체크해야 하며 생년월일·신분증을 수집하거나 연령을 본인인증한 것으로 취급하지 않습니다. 만 14세 미만 가입이 확인되면 이용을 제한하고 관련 계정·정보를 삭제 처리합니다. 법정대리인 동의를 받는 아동 가입 절차는 운영하지 않습니다.

2. 게시물·사진과 회원 활동

코스·장소·봉투함의 제목·설명·위치·경로, 리뷰·평점·사진, 작성자 식별자·표시명·등록 시각은 사용자가 등록한 정보의 게시·수정·신고 처리에 이용합니다. 닉네임·공개 사진·게시물은 다른 방문자와 검색엔진이 볼 수 있습니다. 찜·포인트·알림·신고 기록은 해당 회원 기능에 사용하며 신고 원문은 권한이 있는 관리자만 조회합니다.

이벤트는 가입 후 별도 선택 동의·응모를 받습니다. 응모 자격·중복 확인, 추첨·발표·지급을 위해 계정 식별자·가입 시각·카카오 회원번호를 비밀키로 변환한 중복 확인값·응모번호·응모 시각·동의 버전·당첨·연락 접수·발송 상태를 처리하며 이메일은 당첨자 연락에만 이용합니다. 공개 발표에는 응모번호만 표시합니다. 해당 월 발표일부터 90일 후 매일 자동 정리하며 탈퇴 시 연결된 응모를 삭제합니다. 이벤트 중복 참여를 막기 위한 카카오 중복 확인값·계정 식별자·응모 월은 취소·탈퇴 후에도 해당 월 발표일부터 90일까지 별도로 보관한 뒤 매일 삭제합니다. 카카오 회원번호 원문은 이벤트 중복 확인 기록에 저장하지 않습니다. 발송용 연락처는 당첨 후 별도 동의로 확인하고 발송 완료 후 30일 내 운영자가 삭제합니다. 동의 거부는 일반 회원 기능에 영향을 주지 않으며, 마감 전 응모 취소 또는 문의로 권리를 행사할 수 있습니다.

공개 사진은 공개 URL로 접근 가능한 저장소에 업로드됩니다. 타인의 얼굴·연락처·집 주소 등이 포함되지 않도록 확인해 주세요. 사진·게시물 삭제 요청에는 해당 URL을 알려주세요. 운영 데이터 삭제와 검색엔진·외부 캐시 삭제는 별도 처리일 수 있습니다.

3. GPS 위치와 산책 기록

GPS 기록은 위치정보 이용 선택과 브라우저 위치 권한을 확인한 뒤 시작합니다. 좌표·수신 시각으로 경로·거리·시간과 예상 걸음 수를 기기에서 계산하고 미저장 초안을 브라우저에 보관합니다. 화면 잠금·앱 전환 시 GPS가 중단될 수 있습니다. 예상 걸음 수는 GPS 거리와 보호자 보폭으로 계산한 값입니다.

‘내 기록에 저장’을 누를 때 별도 서버 저장 동의를 확인하고, 계정 식별자와 GPS 경로·구간·거리·기록 시간·일시정지 시간·보폭·예상 걸음 수를 Supabase에 저장합니다. 다른 일반 회원에게 공개하지 않으며 본인과 운영 관리자만 권한에 따라 접근합니다. 문의·장애 대응 외 불필요한 관리 열람을 제한합니다.

‘주변 코스 산책 인원 집계’는 기본 해제된 선택 기능입니다. 선택 시 계정 식별자·인근 코스 ID·갱신 시각을 전송하며 원본 위도·경도는 전송하지 않습니다. 갱신이 끊긴 정보는 5분 후 파기 대상으로 분 단위 정리합니다. 공개 화면에는 코스별 합계만 제공합니다.

동의 해제·위치 권한 철회로 이후 수집을 중단할 수 있습니다. 이미 서버에 저장한 산책은 내 기록 삭제 또는 탈퇴로 별도 삭제해야 합니다. 기기 초안은 ‘기기 기록 삭제’ 또는 브라우저 사이트 데이터 삭제로 제거할 수 있습니다. 자세한 범위는 위치정보 이용 안내에서 확인합니다.

4. 접속 통계·보안·브라우저 저장

방문자 식별자·계정과 연결된 식별자·조회 시각·페이지 경로·유입 출처·홍보 캠페인·활동 화면·화면이 보인 시간·클릭 횟수·스크롤 비율을 이용 분석과 서비스 개선에 처리합니다. 발자국의 방문 통계에는 원본 IP·User-Agent·비밀번호·접속 토큰을 저장하지 않습니다. 인프라 제공자의 운영 로그는 별도입니다.

보안 사건 종류·시각·쿼리를 제외한 경로·확인 가능한 계정 식별자와 비밀키로 변환한 요청 상관 식별자를 권한 보호·부정 이용 대응에 처리합니다. 원본 IP·이메일·비밀번호·접속 토큰은 이 보안 기록에 저장하지 않습니다.

쿠팡 제휴 링크 클릭 시 상품·클릭 시각·페이지·유입 경로·브라우저 및 기기 종류·브라우저 식별자와 로그인 시 계정 식별자를 서비스 분석에 저장합니다. 원본 IP·이메일·URL 검색 매개변수는 저장하지 않으며 구매·수익 정보와 다릅니다. 관리자만 원본 통계를 조회할 수 있습니다.

로그인 세션·방문자 ID·설정·등록 초안·산책 초안은 브라우저 저장소에 보관될 수 있습니다. 사이트 데이터 삭제 시 로그아웃되거나 초안이 사라집니다. 기기 데이터 삭제만으로 서버 데이터가 삭제되지는 않습니다.

6. 처리 위탁·외부 서비스·국외 처리
