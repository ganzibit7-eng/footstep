# 실제 경로 확인 코스 확대 · 2026-10-17

목표는 기존 400곳과 중복 없는 실제 보행 경로 코스 300개 추가다. 장소 위치만 확인된 자료는 추가 수량에 포함하지 않는다. 이 폴더의 manifest 상태와 데이터베이스·배포 검증 결과를 구분한다.

## 1차 조사
- 기존 공개 400곳, 경로 보유 202곳을 기준으로 이름·위치·경로 겹침을 대조.
- 한국관광공사 공개 관광 DB에서 공원 1,767곳 및 길·숲·호수·해변·수목원을 합쳐 고유 후보 3,032곳 조회. 동반 정보 존재 251곳, 전구역 동반 표시 138곳. 이는 공개 코스 추가 수가 아니다.
- 전국 OSM 원본에서 실제 보행로와 일치하는 공원 경계를 대조. 초도 공원 대조에서 5개 경로 후보를 찾았으며 낙산공원은 기존 한양도성 낙산구간과 겹쳐 제외.
- 원본 보행로가 단절되거나 허용 구역이 불명확한 후보, 다른 장소와의 이름·좌표 불일치 및 기존 장소의 중복 후보는 보류.

## 초도 4개 경로
이천온천공원(약 0.78km), 구리한강시민공원(약 0.96km), 울산 공룡발자국공원(약 0.38km), 부산북항 친수공원(약 2.11km).

OSM 원본의 연속 노드·보행로를 연결한 **지도 기반 제안 경로**이며 공식 지정 산책 코스나 현장 답사가 아니다. 공원 경계 안의 실제 보행로만 사용하고 좌표를 보간하거나 끊어진 구간 사이에 선을 만들지 않는다. 거리·계단·경사·쉼터·난이도·통제 확인 범위를 구분한다. 수경·놀이·운동·실내 시설까지 동반 허용으로 확대하지 않는다. 공원 대표 주소는 선택 경로의 출발점 주소와 구분한다.

사진은 해당 관광 DB 장소에 연결된 실제 장소 경관 자료이며 경로 전체 사진이 아니다. 제공 JPEG 원본 바이트와 전체 비율을 유지하고 촬영 시기는 미확인으로 표시한다. 출처·제공기관·개방자료 이용조건을 함께 표시한다.

## 공개 진행
2026-10-17 초도 4개를 approved로 전환했다. 공개 합계 404곳, 경로 보유 206곳이며 목표 300개 중 신규 4개다. 나머지는 조사 중이며 위치 안내만으로 목표 수량에 포함하지 않는다.

## 추가 조사 범위
공개 관광 DB 조사 범위를 정원·유원지·습지·하천·섬·해수욕장·오름·저수지로 넓혀 고유 후보 4,890곳을 대조했다. 동반 자료가 있는 367곳 중 전구역 표시 202곳이지만, 이는 기존 공개 장소와 중복 및 경로 미확인 자료를 포함하므로 신규 코스 수가 아니다.
종댕이길은 공식 GPX 140개 좌표 모두 일치, 기존 400곳과의 경로 중복 없음, 해당 길의 전구역 동반 안내·실제 장소 사진을 확인했다. 사진·검증 모듈 배포 후 원본 경로 해시 조건으로 한 건만 공개했다.

최신 공개 합계: 405곳, 경로 보유 207곳. 이번 신규 공개는 목표 300개 중 5개(공식 GPX 1개·지도 기반 제안 4개)이며, 300개 목표는 미완료다.

## 후속 공개 · 원본 보행로 2곳
암남공원(약 1.86km)·유구색동수국정원(약 1.09km)의 경로·동반 범위·실제 장소 사진·중복 검사를 마쳐 공개했다. 암남공원 사진은 구름다리 대신 실제 공원 입구 사진으로 선택했으며 제안 경로에 구름다리·케이블카·유료시설은 포함하지 않는다. 공원 경계에 정확히 놓인 끝점 2개를 포함해 모든 선분이 해당 장소 경계 안에 있음을 별도 공간 연산으로 대조했다.
최신 공개 합계: 407곳, 경로 보유 209곳. 이번 신규 공개는 300개 목표 중 7개(공식 GPX 1개·지도 기반 제안 6개)다. 목표는 아직 미완료다.
