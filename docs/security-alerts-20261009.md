# 관리자 보안 알림

관리자 보안기록은 기본 접힘 details이며 기간 선택·새로고침을 유지합니다. 알림함의 보안 알림에서 바로 기록을 펼쳐 확인할 수 있습니다.

서버가 보안 사건을 저장하면 private 트리거에서 실제 관리자 계정에만 notifications를 생성합니다. 권한 거절·승인 우회·계정 삭제 실패는 첫 서버 기록부터, 로그인 실패는 10분에 5건, 기타 서버 경고는 3건, 브라우저 보고는 5건부터 알립니다. 동일 출처·종류별 30분 쿨다운은 원자적 UPSERT로 제어합니다. 브라우저 보고는 미확인으로 표시하며 공격으로 단정하지 않습니다.

관리자에게 기존 알림함의 점 표시를 전달하며 홈페이지가 보이는 동안 30초마다 확인합니다. 화면을 다시 열면 확인합니다. 사이트를 닫았을 때 휴대폰 푸시·문자·이메일을 보내는 기능은 아닙니다.

일반 회원은 알림 생성 함수와 기록 테이블에 접근할 수 없습니다. 알림 조회/읽음 처리는 본인 소유에 제한되고, 현재 표시한 ID만 읽음 처리해 동시에 도착한 새 알림을 보존합니다. 계정 변경 중 도착한 이전 조회 응답은 무시합니다.

검증: tests/security-alerts.sql의 서버 단건/임계치/30분 재알림/관리자 수신자/일반 회원 조회 및 함수 호출 거절/관리자 조회 통과. 전체 트랜잭션 ROLLBACK, 테스트 계정 잔존 0 확인. security-notifications.cjs, security-monitor.cjs, security-edge.mjs 통과. 보안 어드바이저에 새 공개 definer 함수 경고 없음. private.security_alert_state의 RLS 정책 없음은 클라이언트 접근을 완전히 차단하려는 의도입니다.
