전체 116개 코스를 조사하고 실사진 72장을 82개 코스에 적용했습니다. 34개 코스는 보류했습니다. 기존 9개 코스에 이어 이번에 73개 코스를 추가했습니다.

## 사진 선택과 표시

- Commons에서 한국어 코스명, 영문 지명, 촬영 위치 주변을 검색하고 후보 메타데이터를 확인했습니다. 서울연구데이터서비스에서는 대상지·촬영지·개별 라이선스 표시를 추가 대조했습니다. 검색 결과만으로 장소를 확정하지 않았습니다.
- 서울연구원 자료는 개별 페이지에 공공누리 1유형과 CC BY 4.0이 함께 표시된 공개 이미지만 사용했습니다. 회원 동의나 이메일 요청이 필요한 고해상도 다운로드 절차는 이용하지 않았습니다.
- Commons 사진은 개별 파일의 CC BY / CC BY-SA / CC0 표시와 원저작자 정보를 확인했습니다. 이번 추가분에서는 미검토 외부 라이선스, 이용 제한 문구 충돌, FoP 주의 표시, 장소 불일치 후보를 제외했습니다.
- 얼굴·차량번호·현대 조형물 등이 주제가 되는 사진은 피하고 경관·산책 구간 중심으로 선정했습니다. 서울연구원의 개인정보 모자이크 처리 방침도 확인했습니다.
- 원작자·제공기관, 사진 제목, 원본 상세 페이지, 사진 라이선스 링크, 촬영 시기, 변환·잘림 내역을 카드·상세 화면·정적 상세 페이지에 표시했습니다. BY-SA 사진의 변환본은 동일한 사진 라이선스로 제공합니다.
- 넓은 공원 사진이나 코스 주변 사진은 캡션에 실제 장소와 주변 여부를 표시합니다. 과거 사진을 현재 모습이나 전체 경로의 보증으로 설명하지 않습니다.
- 확인 자료는 라이선스가 권리자에 의해 적법하게 부여되었다는 절대적인 보증이나 모든 제3자 권리의 해소를 뜻하지 않습니다. 자료 제공자의 조건이 바뀌거나 권리 이의가 들어오면 해당 사진을 다시 검토해야 합니다.

## 근거와 유지관리

- [서울연구원 사진 저작권·출처 표기 정책](https://data.si.re.kr/node/65064#photo-rights)
- [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- `license-evidence.json`: 채택 사진의 개별 라이선스 메타데이터 및 공식 페이지 표시 확인 기록.
- `courses.json`: 전체 코스의 조사 상태, 검색어, 경유지, 반영 사진 및 보류 이유.
- `assets/course-photos/credits.json`: 실제 서비스에서 사용하는 사진·출처 원장.
- 사진 원장 변경 후 `node scripts/sync-course-photos.cjs`로 브라우저 모듈과 정적 상세 페이지를 맞춥니다. 이름이 달라진 코스에 사진이 잘못 붙지 않도록 ID와 이름을 함께 검사합니다.
