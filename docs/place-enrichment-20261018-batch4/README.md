# 기존 동반장소 대량 보완 — 2026-10-18

공식 관광 자료 49,601건과 기존 승인 장소 3,133곳을 대조했다. 도로명·건물번호, 고유 상호 및 100m 이내 좌표가 일치한 자료만 연결했고, 여러 후보·기존 출처와 불일치한 후보는 제외했다.

422곳에 사진 1,185장을 추가해 연결 사진은 3,614장, 사진 보유 장소는 1,040곳이 됐다. 추가 원본 파일 1,156개를 비공개 R2에 저장하고 전체 파일 해시·크기·형식을 검증했다. 전체 사진 원본은 3,573개, 1,289,613,011바이트다. 공식 제공 사진의 크기 변형은 같은 리소스 ID로 중복 제거하고 제공된 파일 바이트·전체 비율을 유지했다.

공식 상세 동반 조건 1곳, 소개 동반 안내 1곳, 방문 정보 786곳(문의처 769곳), 별도 반려견 관련 상세 안내 7곳을 보강했다. 일반 운영 정보·요금 자료를 반려견 전면 허용이나 모든 객실 출입 허용으로 변환하지 않았다. 기존 상충·제한 경고 23곳과 미확인 체중·실내 출입 표기를 보존했다.

공식 상세 재대조에서 210곳은 주소·상호·좌표 일치를 재확인하지 못해 새 자료를 연결하지 않았다. 한 상세 요청은 시간 초과, 사진 주소 204개는 404, 사진 1개는 파일 형식 확인 실패로 제외했다. BMP 등 현재 사진 통로에서 지원하지 않는 제공 파일은 임의 변환하지 않았다. 재사용 가능한 사진이 아직 없는 장소는 2,093곳이며 없는 사진·조건을 만들어 채우지 않았다.
