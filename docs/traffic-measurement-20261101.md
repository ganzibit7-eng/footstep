- 첫 클릭이 최초 전송 후2초 이내면 전송을 건너뛰었다. 첫 신뢰 클릭은 즉시 전송하며 이후 클릭의 기존 제한/진행 중 요청 병합은 유지한다.
- visibilitychange 경계의 마지막 노출 분수를 반영하고 숨김 시간은 복귀 시 더하지 않는다. 기존 회당2초 상한은 유지한다.
- 관리자 검색·상세 영역에 활동 기준 충족 비율과 미충족 브라우저 수 추가. 기존 RPC의 measured_visitors와 engaged_visitors만 사용. 미수신/불일치/분모0은 미집계, 임의0/음수/봇 재분류 없음.
- 일반 분류는 사람 인증이 아니며, 상세 비중은 자동 신호/운영자 제외 후 조회 횟수 비율이라는 설명을 표시. 미충족 조회도 포함됨을 명시. 오늘 진행 중·한국 시간 마감 시각 안내 추가.
- 관리자 모듈·홈 수집 파일 버전 갱신, SW v226-measurement. 정적 생성기·공통 게시기의 수집 URL도 갱신해 재생성 시 보존. 기존 상세 페이지의 이전 버전 URL도 같은 공통 traffic.js 파일을 사용한다. HTTP 캐시가 만료/재검증되기 전까지 이전 파일이 잠시 남을 수 있으며, 기존 열린 탭의 실행 중 코드를 소급 교체하지 않는다. 수만 개 정적 문서는 별도 재생성하지 않았다.
