# 발자국 순차 보완

사용자가 `.`을 보내면 아래 순서에서 다음 단계 하나를 구현·검증·배포한다.
기존 홈 디자인, 로그인, 지도, GPS, 검색, 데이터 연결을 유지한다.

1. 카드 사진 설명 축약 — 구현 및 테스트 완료. 출처·라이선스·편집 표시 유지, 상세 정보 접기.
2. 코스 표시 제목 정리 — 다음 단계. 원본 이름과 사진 매칭은 유지.
3. 산책 기록 시작 버튼 우선 배치, 준비·설정 접기.
4. 검색·필터 구성 압축.
5. 비회원 지역 선택.
6. 지도 검색의 일반 장소와 확인된 애견동반 장소 구분.
7. 코스 출발점·인근 주소·주차 정보 구분.
8. 코스·장소 지역 및 유형 다양성 보완.
9. 사진·일러스트 카드 표현 통일.
10. 서비스 소개 문구 간결화.
11. 작은 글씨 및 로그인 안내 정리.
12. 초기 데이터 로딩과 성능 보완.

완료 기준: 관련 검증 통과, main 반영, 배포 성공 확인. 실제 모바일 GPS 테스트는 별도로 수행해야 한다.
