# 발자국 쿠팡파트너스 추천 영역

홈의 코스 추천과 서비스 안내 다음에 산책 준비물 3종을 연결합니다. 현재는 구매 링크 없이 준비물의 필요 이유와 선택 기준을 보여줍니다.

- 배변봉투: 수거 장소까지 사용한 봉투를 가져가는 상황
- 휴대용 급수병: 산책 중 쉬는 상황
- 목줄·하네스: 출발 전 크기와 연결 상태 확인

`shopping-config.js`의 각 `url`에 본인 계정에서 생성한 `https://link.coupang.com/a/...` 제휴 링크를 입력합니다. API 비밀 키를 프런트엔드에 입력할 필요가 없습니다. 일반 쿠팡 URL은 구매 버튼으로 표시하지 않습니다.

링크가 설정된 카드만 구매 비교 버튼을 표시하며 제휴 수수료 안내를 카드 위에 표시합니다. 가격·할인·재고·판매 순위는 표시하지 않습니다. 링크에 포함된 추적 쿼리는 유지합니다.

쿠팡의 검색 결과 URL을 파트너스 ‘간편 링크’로 변환하는 방식도 가능합니다. 활동 채널에 `https://balzaguk.com/`을 등록했는지 확인합니다.

참고: [쿠팡파트너스 공식 이용 가이드](https://partners.coupangcdn.com/partners-guide/partners-guide-20250714121952.pdf), 링크 생성 안내. 2026-10-08 검토.

검증: 설정 전 구매 버튼 없음, 설정 후 제휴 안내와 버튼 동시 표시, 추적 쿼리 보존, 비제휴·위험 URL 거부, 모바일 카드 넘김 구조 확인.
