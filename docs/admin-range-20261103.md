# 관리자 통계 탐색 개선 — 2026-11-03

## 범위와 동작
- 날짜 슬라이더 제거. 그래프의 빈 공간/점을 클릭·터치하면 가장 가까운 날짜를 선택하고 해당 일자의 조회·방문 브라우저·활동 확인을 함께 표시.
- 좌우 방향키, Home/End, 이전/다음 날짜 버튼 지원. 지표 전환·화면 폭 변경 후 선택 날짜 유지. 일별 표와 CSV 보존.
- 오늘/7일/30일/90일과 직접 시작일·종료일 선택을 동일한 KST 집계 경로에 연결. 종료일 포함, 오늘은 조회 시각까지만, 과거 날짜는 하루 전체. 최대 366일, 미래/역순/누락 날짜 거부.
- 범위의 방문 브라우저는 서버에서 DISTINCT 집계. 일별 방문자 합으로 대체하지 않음. 봇 상세·유입·페이지·경험 통계·CSV는 적용한 기간을 따름. 보안 기록·제휴 클릭 등 별도 업무의 필터는 유지.
- 현재 기간 진행 상태와 과거 종료 기간 안내 구분. 날짜 범위는 한 번만 표시해 요약 카드의 중복 날짜를 줄임.

## 실제로 확인한 문제 및 해결
- 원래 차트는 range 슬라이더만으로 날짜를 선택. 모바일 SVG가 큰 고정 viewBox로 축소되어 작은 글씨·낮은 그래프가 됨. 실제 영역 폭으로 좌표를 계산하고 ResizeObserver로 재배치.
- 일반 flex 공통 규칙이 날짜 form을 142px로 줄여 입력이 잘림. 날짜 전용 flex-basis 및 모바일 한 줄 입력 구성으로 수정. 16px 입력 글자 유지.
- 기존 SECURITY INVOKER 집계를 그대로 확장했을 때 12일/31일 조회가 57014로 실패. 봇의 중복 조건 호출을 단축해 12일은 해결됐지만 31일은 계속 실패.
- 신규 private 집계 함수 2개가 auth.uid + is_admin을 먼저 확인하고, 범위가 제한된 읽기 집계를 수행하도록 변경. 공개 RPC 2개는 INVOKER wrapper. private 함수는 검색 경로 비움, 고정 SQL, STABLE, PUBLIC/anon 실행 금지, 내부 관리자 검사. 기존 테이블·RLS·관리자 역할·원래 preset 함수·수집 규칙은 변경하지 않음.
- 성능 문제를 이유로 역할 제한시간이나 RLS를 끄지 않음. 큰 조회 실패 시 범위를 줄이라는 안내와 재시도 제공.
