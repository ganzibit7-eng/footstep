# 전국 반려견 동반 산책 위치 확대

기존 공개 정보 226곳을 보존하고 공식 자료로 동반 조건을 확인한 174곳을 추가 준비했다. 신규 자료는 장소 정보이며 검증된 전체 걷기 경로가 아니다. 거리·난이도·계단·경사·쉼터·경로 출발점은 미확인으로 유지한다. 공개 여부는 manifest.json의 status와 실제 데이터베이스 및 배포 확인 결과로 판단한다.

각 장소의 한국관광공사 원문, 대표 주소·좌표, 자료 확인일, 체중·등록·접종·입마개·허용 구역 제한을 기록했다. 운영기관 규정이 더 엄격한 남이섬, 태산패밀리파크, 인천대공원 및 대전 반려동물공원 등의 조건은 운영기관 안내를 우선한다. 실내시설·사유시설·당일 통제는 개별 확인이 필요하다.

사진은 실제 장소의 경관·시설 참고사진이다. 현재 개화나 날씨 및 반려견이 이용 가능한 전체 동선을 보증하지 않는다. 사진별 사용 허락이 확인된 CC·공공누리 사진과 한국관광공사의 국문 관광정보 개방자료 사진을 사용한다. 개방자료 사진의 개별 공공누리 세부 유형이 표시되지 않는 경우 유형을 임의로 지정하지 않고 출처 및 원본 유지 조건을 표시한다. 공개된 자료의 contentId·제목·이미지 URL과 사진 원본 해시를 연결했고, 변경 금지 조건까지 지키도록 원본 JPEG 바이트와 전체 비율을 유지한다.

개방자료 이용조건: https://www.data.go.kr/data/15101578/openapi.do

다른 지역의 동명 장소 사진, 차도 위주의 사진, 중복 권역 및 불명확한 동반 조건은 이번 추가에서 제외했다. 기존 코스 데이터·사진·주소·동반 근거의 변경 여부는 기준 해시로 검사한다.
