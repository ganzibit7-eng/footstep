# 2026-11-13 운영기관 근거 산책코스 보강

공개 산책코스 498곳에서 출발해 서울시 미래한강본부, 제주관광공사, 경상남도 반려동물 여행지도 및 한국관광공사 장소별 관광·반려동물 자료를 대조했다. 사진 권리가 표시된 후보 자료 471건을 모았으며, 기존 목록과 위치, 동반 조건, 사진 속 장소를 대조해 28곳을 선정했다. 공개 코스는 526곳이다. 확인일은 공개 문서 확인일이다.

- 서울 광나루한강공원은 일반 강변 보행로를 안내하며 암사생태공원 등은 범위에서 제외했다. 담양 메타세쿼이아길은 맨발로 걷는 흙길을 제외했다. 포천 비둘기낭폭포는 15kg 이하, 울산 대왕암공원 출렁다리는 이동장 조건을 표시했다.
- 제주관광공사 안내에 따라 곽지·금능은 육상에서만 산책할 수 있고 반려견 입욕은 불가하다고 표시했다. 함덕은 일반 육상 잔디공원 산책으로 한정했다. 경상남도 자료의 동정호와 신선대는 각각 호숫가와 야외 전망 구간을 안내한다.
- 광나루·잠원·잠실 한강공원, 송도 센트럴파크, 하동 동정호, 제주 한담해안산책로는 OpenStreetMap의 연결된 공개 보행로를 제안 경로로 표시했다. 한담은 곽지 쪽 남쪽 구간으로 한정하고 낙석 위험으로 폐쇄된 애월한담공원 쪽 연결 계단을 제외했다. 나머지는 대표 위치와 동반 구역을 안내하며 거리·시간은 비워 둔다.
- 사진 28장의 콘텐츠 ID, 사진별 공공누리 제1·3유형, 원본·표시 파일 해시를 기록했다. 제3유형은 원본 JPEG와 전체 비율을 보존했다. 기존 사진 서버의 원본과 바이트가 일치한 파일만 중복 배포에서 제외했다.
- 재인폭포는 현재 통제 구간과 동반 허용 범위를 대조할 때까지 보류했다. 난지한강공원·반포한강공원·낙산공원은 기존 코스와 중복됐다. 조례호수공원과 미사호수공원 등 나머지 보류 근거는 `batch.json`에 기록했다.
