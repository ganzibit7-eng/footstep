# 2026년 11월 13일 반려견 동반 산책코스

공개 코스 417곳과 중복을 대조하고 한국관광공사 자료의 동반 범위와 사진별 이용 조건을 확인했습니다. 신규 13곳은 야외 보행 구간을 안내합니다. 순천 고인돌공원은 10kg 이하 및 일부 견종 동반 가능으로 표시합니다. 허용 견종의 세부 목록과 실내 시설 출입 여부는 자료에 기재되어 있지 않습니다.

진천 농다리, 대구 경상감영공원, 진안 부귀 메타세쿼이아길, 고양 행주산성 역사공원은 OpenStreetMap에 기록된 연결 보행로를 **제안 경로**로 표시합니다. 나머지 9곳은 한국관광공사 대표 위치를 표시하며 출발점, 경로선, 거리를 등록하지 않습니다. 제안 경로도 현장 답사를 거치지 않았으며 기상·행사·공사로 인한 현장 통제가 적용될 수 있습니다.

실제 경관 사진 13장을 등록했습니다. 공공누리 제1유형 사진은 전체 비율을 유지해 WebP로 축소했고, 제3유형은 제공된 원본 파일 그대로 사용했습니다. 사진별 권리와 SHA-256은 [사진 기록](../../assets/course-photos/credits.json)에, 동반 규정 원문·보행 좌표·보류 사유는 [자료 기록](batch.json)에 있습니다.

관광공사 자료와 운영기관 안내가 충돌한 황장목숲길은 이번 등록에서 제외했습니다. 중복 가능성이나 동반 허용 구간의 경계가 남은 곳도 보류했습니다. 지도 데이터 © OpenStreetMap contributors, ODbL 1.0.
