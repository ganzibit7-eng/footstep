# 미사진 코스 추가 조사 — 2026-10-10

이전 조사 후 사진이 없던 93개 코스를 다시 조사했습니다. 이번에는 32개 코스에 실사 사진을 추가했습니다. 전체 362개 중 사진 연결 코스는 269 → 301개, 미사진 코스는 93 → 61개입니다.
