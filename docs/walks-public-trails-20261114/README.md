# 2026-11-14 반려견 동반 산책코스 후속 검증

공개 537곳에서 11곳을 추가해 548곳으로 갱신한다. 한국관광공사 동반 안내의 대상과 조건을 대조하고 OpenStreetMap의 공공 보행로로 이어지는 구간을 선택했다. 장소별 사진 권리는 공사 원본에서 확인했다. 제3유형은 전체 비율과 원본 바이트를 유지하며 장소 상세에 이미 쓰이는 동일 파일은 공유한다. 지리 자료로 확인한 보행 구간은 점선 제안 경로로 표시하며 현장 답사는 하지 않았다.

직전 공식 자료 후보 141건의 미등록분에서 영업시설을 제외한 124건을 지리 검토 대상으로 삼았다. 최근 폐쇄나 통제 소식이 있는 곳과 동반 구역을 지형에 특정하기 어려운 곳을 제외했다. 서우봉은 한국관광공사 동반 안내와 사진을 확인했으나 제안 구간의 약 82%가 기존 제주 함덕해변 잔디공원 코스의 12m 이내에 있어 별도 코스로 등록하지 않았다. 후보·경로 검사는 최종 등록 기준을 통과한 장소의 수와 다르다.

피아노폭포는 남양주도시공사의 보행자 이동 통로 안내, 남양주시의 관람 안내와 경기도의 생태공원 자료를 대조했다. 폭포 관람 공간까지 이어지는 노선도·좌표를 확인할 수 없어서 기존 위치 안내를 유지했다. 각 코스의 근거와 피아노폭포의 추가 자료는 batch.json에 기록했다.
