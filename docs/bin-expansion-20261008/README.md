# 배변봉투 수거 장소 확장 · 2026-10-08

GitHub main 최신본을 확인한 뒤 운영 DB의 기존 4개 장소를 보존하고 34곳을 추가했다. 공개 승인 장소는 총 38곳이다. 추가 장소의 수거 기능은 문서로 검토했으며 현장 답사나 현재 기기 작동 확인을 의미하지 않는다.

- 서울 서초구: 공식 블로그의 2026년 4월 위치 목록 14곳.
- 인천: 공원 11곳. 2024년 설치 자료와 2026년 운영 관련 보도를 함께 검토. 뉴스에서 무주골공원을 남동구로 표기한 오류와 혜윰공원 명칭 차이는 지도·공식 자료와 대조했다. 갈산공원은 매체별 목록이 달라 이번 추가에서 보류했다.
- 경기·울산·거제·김천: 청사·공원·반려견 놀이터·휴양림·야영장 9곳. 북부청사의 수거함 2개는 동일 시설 내 1개 장소로 묶었다.

## 위치와 이용 범위

카카오 지도 공개 검색 결과의 지번 주소 또는 시설 대표 좌표를 사용했다. `kakao-geocoding.json`에 대조 결과를 보존한다. 수거함 자체의 좌표는 확인되지 않았으며 상세 안내와 DB 설명에 이를 명시한다. 하천의 긴 필지는 대표 좌표와 실제 설치 지점 간 거리가 있을 수 있다.

인천 스마트 시설은 풉풉 앱 가입·수거용 QR 및 전용 봉투 이용 안내를 따른다. 놀이터·휴양림·야영장의 입장·예약·요금 조건은 현장 또는 운영기관에 확인해야 하며 일반 산책객에게 무조건 개방된 것으로 안내하지 않는다.

일반 쓰레기통, 봉투 배부 기능만 있는 함, 설치 제안·주민참여예산 미채택 장소는 수거 장소로 추가하지 않았다. 기존 4곳은 삭제·덮어쓰지 않았고 수거 여부 미확인으로 구분했다.

## 반영 파일

- added-bins.json: 신규 DB 행 34개.
- evidence.json / ../../bin-info.js: 자료 출처·게시일·검토일·이용 조건·좌표 한계.
- ../../database_sql/seed_expansion_bins_20261008.sql: 재실행해도 기존 행을 덮어쓰지 않는 데이터 추가 SQL.
- index.html / scripts/generate-seo.mjs: 지도 팝업과 검색 상세에 수거 여부·출처 안내.

로그인·회원·결제·방문 통계 데이터와 보안 정책은 수정하지 않았다. 화면 확인은 로컬에서 방문 집계 스크립트 요청을 차단하고 진행한다.
