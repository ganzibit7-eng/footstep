# 발자국 광고·제휴 운영 중단 (2026-11-17)

- 홈 광고 모집 배너와 문의 모달의 광고 경로를 제거했다. 기존 광고 URL에는 안내 문구와 일반 탐색 링크만 제공하며 검색 색인과 사이트맵에서 제외한다.
- 공개 홈 숙소 카드 10개와 기존 숙소 상세 23곳에서 트립닷컴 제휴 버튼과 관련 고지를 제거했다. 페이지 생성기에서도 이 버튼을 만들지 않는다. 숙소 URL, 사진, 동반 조건, 지도 및 찜은 기존대로 제공한다.
- 이전 광고 및 제휴 설정 파일·소재를 배포에서 제외했다. 서비스 워커 버전을 갱신해 이전 사이트 캐시를 정리한다. 쿠팡 판매 링크·광고 스크립트가 공개 HTML에 남지 않았는지 전수 검사한다.
- 관리자에서 광고 등록 및 외부 상품 연결 도구를 비활성화했다. 기존 통계와 데이터를 보존했다. 운영 데이터에서 활성·예약 광고 0건, 크몽 연결 없음, 광고 저장 기록 1건을 읽기 전용으로 확인했다.
- 외부 제휴사 계정이나 계약은 이번 사이트 변경의 대상이 아니다.

## 관리자 접속 호환성 보완

광고 패널을 분리하면서 정정 요청과 경로 초안이 공유하던 관리자 세션 참조가 빠졌다. 두 화면이 현재 관리자 세션을 다시 확인하도록 연결했다. 기존에 열어둔 화면의 관리자 로더가 요청하는 옛 JS 주소에는 안내만 담은 호환 파일을 제공한다. 공개 배너, 제휴 링크, 광고 설정 및 기존 권한은 영향을 받지 않는다.
