## 나머지 15,627곳 전수 조회 준비

조회 대기 목록은 작업 폴더의 `pending-queue.json`에 생성했다. 주소가 온전한 1,083곳은 주소 검색, 마스킹된 14,544곳은 업체명·행정구역 기반 장소 검색 대상으로 분리했다. 마스킹된 숫자를 유추하거나 원본 비식별 좌표를 역산하지 않는다.

`node scripts/research-professional-locations.mjs --help`로 실행 방법을 확인한다. 공식 문서: https://www.vworld.kr/dev/v4dv_search2_s001.do . 인증키는 환경변수 `VWORLD_API_KEY`로만 전달하고 `VWORLD_DOMAIN`에는 발급 시 허용한 발자국 도메인을 지정한다. 키·요청 URL은 로그나 저장소에 기록하지 않는다. 결과 파일은 작업 폴더에만 저장하고 API 결과의 저장·표시 조건을 확인한 후 근거 자료로 검토한다. 인증키 없는 상태에서는 외부 요청을 보내지 않는다.

단일 순차 요청과 요청 수 제한을 적용하며, 이미 조회한 자료는 다시 요청하지 않는다. 제공자 오류·일일 한도 도달 시 중단한다. 후보가 하나이고 업체명·관할 지역·알려진 도로명이 모두 맞는 경우에도 먼저 검토 대상으로 기록하며 자동 배포하지 않는다. 전체를 조회하는 것과 전체의 정확한 위치가 확보되는 것은 다르다. 검색 누락·동명·폐업·이전은 추가 수동 대조가 필요하다.
