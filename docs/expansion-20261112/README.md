# 전국 반려견 동반장소 확대 · 2026-11-12 자료 대조

신규 장소 383곳은 일반음식점 152곳, 휴게음식점 73곳, 제과점 8곳과 캠핑장 150곳이다. 기존 3,775곳에서 4,158곳으로 늘어나며, 전문업소를 포함하고 중복 1곳을 제외한 반려생활 장소 합계는 21,855곳이다.

음식점은 11월 12일 식품안전나라 명단 2,908건에서 같은 상호·도로명·건물번호를 확인하고 소상공인시장진흥공단의 2026년 9월 30일 상가 좌표와 대조했다. 지점명, 지도 좌표, 중복 또는 이전 자료와의 충돌이 해결되지 않은 후보는 보류했다. 명단에 세부 구역이나 견종별 조건이 없으면 상세 페이지에 확인이 필요하다고 표시한다.

고캠핑의 반려동물 동반 검색 결과 1,652곳을 기존 등록 자료와 대조한 뒤, 추가 후보 683곳의 개별 상세를 확인했다. 좌표와 현행 출입 항목을 확인했고, 상세 소개에서 상충하는 안내가 있거나 수정일이 1년을 넘긴 후보를 제외했다. 150곳 중 72곳에는 소형견 제한을 표시한다. 사이트·객실·대여 시설별 출입은 출처에 명시된 범위까지만 안내한다. 운영기관에 전화를 걸거나 현장을 방문하지 않았다.

영덕 카카베이커리, 거제 카페 채홍, 제주시 커피냅로스터스제주의 현장 사진을 추가했다. 사진별 출처와 공공누리 유형을 확인했으며 원본 JPEG와 전체 비율을 보존했다. 사진 속 공간에 반려견 출입이 허용된다는 뜻으로 표시하지 않는다.

[검증 원장](proof.json)에 장소별 상호·주소·좌표·출입 항목과 사진의 원본 주소 및 해시를 기록했다. 이전에 공개 보류된 장소는 공개 승인 대상으로 포함하지 않았다.

되돌리기 모의 등록에서 중복과 행 보안 상태를 검사했다. 실제 등록 후 비회원 공개 조회로 신규 383곳을 모두 대조했다. 승인 4,158곳과 보류 446곳이 확인됐으며 행 수준 보안이 활성 상태다. 생성된 상세와 검색 인덱스·사이트맵을 전수 비교했고, 브라우저에서 사계풀포레스트의 사이트 제한과 카카베이커리의 사진·출처를 확인했다. 공개 원본 크기는 971,228,635바이트로 975MB 배포 검사 기준 이하다.
