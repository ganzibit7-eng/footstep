# 2026-10-03 산책로 확장

기존 124개에 47개를 추가한 뒤, 같은 기준으로 29개를 추가해 총 200개를 구성했다. 자료 확인은 공식 문서와 공개 좌표 검토이며 현장 답사 인증이 아니다.

첫 단계 47개는 공식 GPX 27개와 실제 연결 보행로 제안 20개다. 두 번째 29개는 공식 GPX 전체·선택 구간 18개와 OSM 보행로 제안 11개다. 각 제안은 공식 지정 코스와 구분하고 거리와 양 끝 좌표를 표시한다. 분리 GPX 구간은 연결선을 만들지 않는다.

review.json.gz와 completion-review.json.gz는 출처 식별자, 동반 조건, 표시 좌표, GPX 해시 또는 OSM 원본 노드·웨이를 보존한다. 장문 관광 소개와 검색 결과 본문은 저장하지 않는다. 호수 주변 구간은 실제 지도 보행로 또는 GPX를 해당 호수 위치와 대조했다. 단순히 대표 위치를 임의로 연결하지 않았다. 울산대공원·올림픽공원·중외공원·동락공원은 제한 시설의 지도 영역을 보수적으로 제외했다. 해변의 계절 제한, 사계해변 입수 금지, 입마개·목줄 조건, 산길 경사, 장거리와 강변 침수 공지 등을 설명에 반영했다.

동반 범위를 특정하지 못한 일부 구역 허용 장소, 통제 범위를 확정하지 못한 해안 공사, 위치가 맞지 않거나 큰 단절이 있는 GPX는 보류했다. 사진은 장소와 개별 재이용 허락을 별도로 확인하고, 같은 이름의 다른 지역 사진과 추가 이용 제한이 있는 사진은 제외했다. 사진이 없는 곳에 다른 장소 사진을 대체하지 않는다.
