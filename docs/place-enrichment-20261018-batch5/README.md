# 기존 동반장소 사진·조건 보완 — 2026-10-18 (5차)

사진이 없던 19곳에 공식 원본 42장(대표 19장·추가 23장)을 연결했다. 사진 보유 장소는 1,040곳에서 1,059곳, 전체 사진 연결은 3,656장이다. 같은 원본 4장은 기존 저장 경로를 재사용했고 새 원본 38개는 26,187,005바이트다.

113개 후보 중 공식 상세의 상호·주소·좌표가 재확인된 112곳만 자료를 보완했다. 정확한 상호와 35m 이내 위치 또는 도로명·건물번호와 고유 상호 및 300m 이내 위치가 일치하는 단일 후보만 허용했다. 모호하거나 기존 출처와 충돌하는 후보는 제외했다. 동반 상세 32곳을 재확인했으며 새 구조화 동반 정보 1곳, 소개 내 동반 안내 9곳, 방문 정보 23곳을 보강했다. 기존 제한 경고 23곳과 미확인 체중·견종·실내 허용 표시는 보존했다.

사진은 한국관광공사 국문 관광정보 개방자료의 재사용 가능한 원본만 사용했다. 사진별 출처·원본 주소·해시·크기·조회일은 selected.json.gz에 보관했다. 제공 바이트와 전체 비율을 유지했고 촬영일·촬영자를 추정하지 않았다. 사람이 크게 보이는 사진과 차량 식별 정보가 우려되는 사진 2장은 제외했다. 별도 저작권 안내가 있는 고캠핑 웹페이지 사진은 사용하지 않았다.

권리 안내: https://www.data.go.kr/data/15101578/openapi.do

새 사진은 기존 Pages 용량 여유 안에서 assets/place-photos-supplement/에 저장한다. 기존 R2 사진과 경로는 유지하고 새 R2 키나 계정 권한은 생성하지 않았다. 재사용 가능한 사진이 없는 2,074곳은 임의 이미지로 채우지 않았다. 공식 자료 조회는 실시간 현장 허용을 보증하지 않으므로 방문 전 확인 안내를 유지했다.

summary.json은 전후 수치, reviewed.json.gz는 상세 재대조, matches.json.gz는 후보 매칭 근거, new-files.json은 새 파일 무결성 목록이다.
