# 사진 미보유 장소의 동반 안내 보강 — 2026-10-20

사진과 추가 소개 참고가 없던 기존 캠핑장 412곳을 고캠핑 공개 페이지와 상호·주소까지 대조했다. 90곳에서 반려동물 관련 소개 문장을 찾았으며, 기존 표기의 단순 반복을 제외하고 49곳에 체중·마릿수·준비물·일부 객실·예약·전용 시설 등의 소개 참고를 추가했다. 기본 동반 가능 표기와 소개 문구가 상충하는 6곳에는 허용 구역·객실 재확인 주의 표시를 추가했다. 안내가 상충하는 곳을 현재 동반 가능 또는 불가로 확정하지 않는다.

소개의 수정일은 2019~2026년으로 다양하다. 조회일 2026-10-20을 정책 변경일로 사용하지 않고 원문 수정일을 함께 표시한다. 기존 구조화 동반 조건·필터용 허용 값·캠핑 정보 확인일은 변경하지 않는다. 낡은 대형견 허용 표현이나 요금은 최신 정책으로 올리지 않고 펼쳐 읽는 참고 안내에만 남긴다. 상충하는 경우 기존 재확인 처리 방식을 적용한다. 세부 체중·실내·객실 조건의 미확인은 임의로 채우지 않는다.

원문에는 중·대형견 중심 시설도 맹견·미중성화 수컷 제한이 명시돼 있어 제한을 생략하지 않는다. 객실 입실 불가를 캠핑장 전체 출입 불가로 확대하지 않는다. 조건 관련 사실만 요약하고 다른 서비스의 장문 소개나 사진을 복제하지 않는다. selected.json.gz에는 원문 조건 문장·수정일·주소 대조·공식 출처를 보존했다.
