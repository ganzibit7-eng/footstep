# 전국 장소 보완 — 2026-10-20 세 번째 묶음

- 새 장소 121곳과 기존 4곳을 별개로 집계합니다. 사진 125장. 기존 사진 없는 항목에만 추가하며 기존 사진을 교체하지 않습니다.
- 신규 구조화 동반 조건 21곳, 공식 소개의 한정된 동반 근거 100곳. 소개의 객실·테라스·지정 구역을 시설 전체 허용으로 확대하지 않습니다. 미확인 견종·체중·입실·준비물은 미확인으로 유지합니다. 날짜는 자료 대조일이며 현장 답사·운영정책 갱신일이 아닙니다.
- 사진은 개별 Type1/Type3만 사용하고 원본 파일·비율·크레딧을 유지합니다. 다국어 사진은 동일한 한글 장소명·근접 좌표·언어별 사진 권리를 따로 대조합니다. 국문에서 상업 이용이 제한된 동일 사진 ID와 겹치는 대체 사진은 사용하지 않습니다.
- 기존 4곳은 별칭·주소를 대조해 신규로 세지 않습니다. 기존 동반 제한·고캠핑 사실표·재확인 안내는 보존합니다.
- 캠플레이의 두 공식 좌표가 다릅니다. 고캠핑 주소는 가평군인데 대표 좌표는 다른 지역을 가리켜, 같은 주소의 한국관광공사 대표 좌표로 1곳을 정정합니다. 정확한 출입구 좌표는 미확인입니다. 원본은 location-corrections.json 및 기존 증명에 남깁니다.
- 공개 승인 전 manifest는 pending 상태이며 ID·설명 해시가 일치할 때만 공개합니다. 좌표 정정도 기존 이름·주소·설명 해시·이전 좌표가 일치할 때만 같은 트랜잭션에서 수행합니다. 회원·로그인·권한·개인 GPS 기록은 변경하지 않습니다.
- 홈 수는 실제 공개 승인 후 수동 갱신하며 사진 보완 4곳은 신규 숫자에 더하지 않습니다.
