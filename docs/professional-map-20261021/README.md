# 전국 전문업소 지도 연결

2026-10-20에 내려받은 지방행정 인허가 자료의 공개 대상 33,277곳 전체를 연결한다. 새 업소 추가가 아닌 기존 목록의 지도 연결이다. 홈의 반려생활 장소 수는 변경하지 않는다.

- 공개된 비식별 처리 없는 원문 주소에 대응하는 좌표 17,588곳을 사용한다. 이 원문은 동물병원·동물약국 자료다. 미용·위탁관리·운송업의 마스킹된 주소나 좌표를 역으로 복원하지 않는다.
- 동일 업소가 병원과 미용 등으로 함께 등록된 경우, 같은 업소의 공개된 병원 원문 좌표를 사용할 수 있다. 상세 목록의 기존 마스킹된 주소는 그대로 유지한다.
- 위치를 확인할 수 없는 15,689곳은 핀 좌표를 만들지 않는다. 지도 아래 접을 수 있는 지역별 목록 링크를 사용하고, 실제 업소 위치가 아니라는 문구와 목록 링크를 제공한다.
- 지도는 축소 시 묶음 표시하고, 한 번에 250개씩 추가하며 조건 변경 시 이전 표시 작업을 취소한다. 홈페이지에서는 지도 자료를 불러오지 않고 위치정보·회원정보를 전송하지 않는다.

좌표는 지방행정 인허가 자료의 EPSG:5174를 pyproj로 EPSG:4326으로 변환한 참고 위치다. 주소코드에 매핑된 값으로 실제 출입구나 운영 상태를 보증하지 않는다. 원본 국가좌표와 관리번호·권리주체 정보는 지도 파일에 포함하지 않는다.

재생성은 기존 `scripts/build-pet-care-data.mjs --source-dir <공식 CSV·JSON·영수증 폴더>` 실행 후 `python scripts/build-professional-map.py --source-dir <같은 폴더>`를 실행한다. Python 환경에 pyproj가 필요하며, 필요시 `--library-dir`로 작업 전용 설치 경로를 지정한다. 생성된 JSON만 배포하며 Python 라이브러리는 배포하지 않는다. 자료 변경 시 홈 중복 집계도 다시 대조한다.

기존 지역 목록 JSON과 지도 인덱스의 모든 ID·업종·공개 주소 일치 여부를 `tests/professional-map.cjs`에서 확인한다. 업종별 수는 복수 업종 때문에 서로 중복된다.

2026-10-22 위치 보완: 독립된 공개 영업장·관광정보 및 같은 도로명 건물의 공공 좌표로 62곳을 추가 연결했다. 현재 지도 표시는 17,650곳, 미표시는 15,627곳이다. 근거와 불확실성 구분은 ../map-location-20261022/README.md 및 data/pet-care/verified-locations.json을 참고한다.
