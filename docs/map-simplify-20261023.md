# 지도 중복 정리와 홈 제목 — 2026-10-23

- 홈 1~4번 및 지역 선택 후 제목은 같은 글꼴·크기 변수(PC 30px, 모바일 24px, 360px 이하 22px)를 사용한다. 1번에 따로 남아 있던 디자인 시스템의 30/26px 규칙은 제거하고 공통 스타일 버전을 갱신한다. 사진·카드·배경·모션·제목 문구는 유지한다.
- 지도 빠른 업종 버튼은 장소 종류 선택과 중복되어 제거한다. 장소/전체의 기존 종류 선택·이름 검색·초기화·재시도·전문업소 연동은 보존한다.
- 지도 아래의 외부 ‘목록 보기’ 버튼을 제거한다. 지도 안 ‘목록 열기/접기’를 탐색 목록의 유일한 제어로 유지하며, 별도 산책 코스 목록은 기존 주 메뉴에서 접근한다.
- 상시 반복 안내를 없애고 실제 코스 검색 조건이 있을 때만 조건 수·해제 안내를 표시한다. 이 안내는 산책길/전체에서만 보인다.
- 위치 미확인 업소를 지역 목록으로 보여준다는 오래된 범례 설명을 현재 표시 정책에 맞춰 정정한다. 경로 정확성·GPS·자료·DB 변경 없음.
- 로컬 전체 192개 검사 통과. 실제 조건 유무에 따른 지도 안내 표시 회귀 검사를 포함한 관련 10개 검사도 통과.
