# 홈페이지 가독성 보완 — 2026-10-13

기존 페이지 순서, 초록·크림색, 로고, 산책 사진, 정보 출처와 미확인 표시는 유지한다.

## 공개 사이트 참고

- [토스](https://toss.im/): 한국어 제목과 짧은 설명의 위계, 절제된 내비게이션. 공개 홈페이지 화면 관찰.
- [Airbnb](https://www.airbnb.com/): 사진 중심 카드와 제목·부가 정보의 구분, 일관된 탐색 컨트롤. 공개 홈페이지 화면 관찰.
- [AllTrails](https://www.alltrails.com/): 지역·공원·코스 이름 검색, 거리·소요 시간 등 코스 핵심 정보와 주변 코스 탐색. 공개 홈페이지 및 접근성 트리 관찰.

다른 서비스의 사진·코드·고유 글꼴은 가져오지 않았다. 전환율이나 사용자 행동 데이터는 수집하지 않았으며, 위 특징은 공개 화면에 대한 디자인 관찰이다.

## 적용

- 기존 외부 글꼴 요청 4종을 Noto Sans KR(본문)·Jua(로고) 2종으로 정리. 숫자는 표 폭이 덜 흔들리도록 tabular-nums 유지.
- 카드 제목, 설명, 안내, 검색 입력, 비교 버튼의 크기·줄 간격을 정돈.
- 모바일 로고·회원 버튼 줄바꿈 방지, 검색 입력 16px, 하단 메뉴 12px.
- 공지 높이 70px 유지, 작은 글씨와 닫기 버튼 보완.
- 추천 카드가 가장 긴 카드 높이에 늘어나 생기던 빈 여백 제거.
- 기존 로그인·GPS·동의·관리자 권한 로직과 코스 데이터는 변경하지 않음.

기기별 실제 글꼴 로딩 속도와 실기기 GPS는 이번 디자인 검증 범위에 포함하지 않는다.
