# 홈페이지 가독성 보완 — 2026-10-13

기존 페이지 순서, 초록·크림색, 로고, 산책 사진, 정보 출처와 미확인 표시는 유지한다.

## 공개 사이트 참고

- [토스](https://toss.im/): 한국어 제목과 짧은 설명의 위계, 절제된 내비게이션. 공개 홈페이지 화면 관찰.
- [Airbnb](https://www.airbnb.com/): 사진 중심 카드와 제목·부가 정보의 구분, 일관된 탐색 컨트롤. 공개 홈페이지 화면 관찰.
- [AllTrails](https://www.alltrails.com/): 지역·공원·코스 이름 검색, 거리·소요 시간 등 코스 핵심 정보와 주변 코스 탐색. 공개 홈페이지 및 접근성 트리 관찰.

다른 서비스의 사진·코드·고유 글꼴은 가져오지 않았다. 전환율이나 사용자 행동 데이터는 수집하지 않았으며, 위 특징은 공개 화면에 대한 디자인 관찰이다.

## 적용

- 기존 외부 글꼴 요청 4종을 Noto Sans KR(본문)·Jua(로고) 2종으로 정리. 숫자는 표 폭이 덜 흔들리도록 tabular-nums 유지.
- 카드 제목, 설명, 안내, 검색 입력, 비교 버튼의 크기·줄 간격을 정돈.
- 모바일 로고·회원 버튼 줄바꿈 방지, 검색 입력 16px, 하단 메뉴 12px.
- 공지 높이 70px 유지, 작은 글씨와 닫기 버튼 보완.
- 추천 카드가 가장 긴 카드 높이에 늘어나 생기던 빈 여백 제거.
- 기존 로그인·GPS·동의·관리자 권한 로직과 코스 데이터는 변경하지 않음.

기기별 실제 글꼴 로딩 속도와 실기기 GPS는 이번 디자인 검증 범위에 포함하지 않는다.

## 홈 중복 안내 정리

- 상단 지도·산책 시작과 추천 코스의 전체 보기 진입점은 유지. 빠른 메뉴는 동반장소·준비 가이드 두 개로 정리.
- 같은 세 가지 기능을 반복하던 큰 서비스 소개, 두 번째 지역 검색/링크 묶음, 떠 있는 몽이 버튼과 중복되는 배너 제거.
- 지도 일러스트 안내는 더 둘러보기로 이동. 주제별 산책 링크와 지역 가이드, 제휴 상품 고지, 개인 산책 서랍은 보존.
- 리뷰가 없는 대표 코스로 인기 목록을 채우던 처리를 제거. 실제 리뷰가 있는 공개·동반 조건 확인 코스만 리뷰 수/평점순으로 표시하고, 없으면 섹션을 숨긴다.
- 검증: 리뷰 0개/1개/정렬/숨긴 코스 제외/자료 삭제 후 초기화, 지역 선택, 상품 고지, 사진, 비교, 로그인, 산책 준비 검사 및 브라우저 모바일/데스크톱 배치 확인.

## 지역 선택과 코스 검색 통합 / 로그인 안내

- 기존 추천·지역 영역을 한 블록으로 통합. 실제 사진 카드로 대표 지역을 선택하고 선택 목록에서 17개 시·도 또는 전국을 선택한다. 선택 후 지역 카드는 접고 결과와 조건을 표시하며 지역 다시 고르기로 돌아간다.
- 등록 주소가 선택 지역과 일치하는 공개·동반 자료 확인 코스만 표시. 키워드·난이도·시간·계단·경사·쉼터를 교차 적용한다. 주소 미확인 코스는 특정 지역 결과에서 제외하며 전국에서는 열람 가능하다.
- 시간·편의 정보가 미확인인 코스를 해당 조건이 확인된 것으로 포함하지 않음. 조건 초기화는 지역을 유지. 결과가 없으면 조건 완화/다른 지역 안내. 12개씩 표시하고 추가 조회 없이 더 보기.
- 선택한 시·도만 브라우저에 기억. GPS·프로필 지역·기존 목록 필터는 변경하지 않으며 홈 검색을 위한 별도 서버 요청 없음.
- 만 14세 이상 확인과 약관 동의를 한 항목으로 묶고 개인정보 수집·이용 동의는 별도 항목으로 유지. 긴 설명은 열람 가능한 내용 안내로 옮기며 개인정보처리방침 링크는 상시 표시.
- 동의 기본 미체크 및 두 항목이 모두 확인되지 않으면 Kakao·Google·이메일 인증 요청 차단. 정보 처리의 법적 근거·수집 항목·보관 기간은 변경하지 않음.
- 참고: [개인정보 보호법 제22조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335519). 개인정보 수집·이용 동의를 약관과 구분하며 중요 내용은 내용 안내에서 확인할 수 있게 보존.
