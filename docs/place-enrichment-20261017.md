# 기존 동반장소 보완 — 2026-10-17

## 범위와 결과

공개 승인된 기존 동반장소 3,133곳 전체를 대조했다. 신규 장소를 추가하거나 공개 승인 상태를 바꾸지 않았다.

- 공식 관광자료와 정규화한 이름이 같고 등록 좌표에서 250m 이내인 후보가 유일한 경우만 연결했다. 기존 한국관광공사 ID 연결도 이름·좌표로 재검증했다.
- 일치한 장소 953곳 중 사진이 제공된 841곳에 실제 해당 콘텐츠의 대표 사진을 연결했다. 촬영자 이름과 촬영일이 제공되지 않은 경우 제공기관만 표시하고 미상으로 안내한다.
- 441곳의 공식 반려동물 동반 자료에서 동반 범위·크기·준비물·세부 제한·구비시설·사고 대비·비치·구매·대여 항목을 원문 기준으로 연결했다. 같은 내용이 여러 필드에 중복된 경우 화면에서는 반복하지 않는다.
- 나머지 2,292곳에는 사진을 임의로 넣지 않았다. 112곳은 일치하는 공식 콘텐츠의 사진이 비어 있었고, 2,180곳은 이번 이름·위치 기준으로 재사용 가능한 제공 사진의 동일성을 확정하지 못했다. 이는 사진 자체가 세상에 없다는 뜻이 아니다.
- 기존 고캠핑 자료의 ‘소형견만 가능’과 문의처도 조건 표에 반영했다. ‘가능’만으로 체중·대형견·실내 허용을 추정하지 않는다. 자료가 없는 항목은 미확인으로 유지한다. 기존 자료 확인일은 새 사진 추가만으로 갱신하지 않는다.

## 출처와 사진 이용 방식

- 국문 관광정보 개방자료: https://www.data.go.kr/data/15101578/openapi.do
- 공식 공개 관광 상세 자료: https://api.visitkorea.or.kr/hub/public/getTourCatDetail.do
- 공식 공개 반려동물 동반 자료: https://api.visitkorea.or.kr/hub/getPetInfo.do

공공데이터포털은 국문 관광정보 서비스가 자유롭게 활용 가능한 관광정보와 사진을 선별 제공하고 공공누리 1·3유형 이미지를 제공한다고 명시한다. 자료별로 원본 제공 URL과 개별 관광 콘텐츠 ID를 기록한다. 정확한 유형을 임의로 1유형이라고 단정하지 않으며, 변경금지 조건도 충족하도록 제공 파일의 바이트와 전체 비율을 유지했다. 자르기·색상 변경·문구 삽입·로고 사용을 하지 않는다. 워터마크를 제거하지 않는다. 기록된 SHA-256으로 제공 파일 무변경을 검증한다.

메타데이터는 `place-evidence.js`에 공개 장소 ID·이름·주소·좌표와 함께 저장한다. 화면은 동일 ID라도 이름·주소·위치가 바뀌면 사진 연결을 중단한다. 원래 설명이 바뀌면 별도로 대조한 동반 조건도 적용하지 않는다. 민간 업소의 인터넷 사진은 공개 접근 가능하다는 이유만으로 복사하지 않았다.

사진은 촬영 당시 제공 자료이며 반려견의 해당 시설 전체 출입이나 당일 운영을 보증하지 않는다. 경관·메뉴·객실 등 제공 사진의 성격을 과장하지 않고 ‘공식 관광자료 제공 사진’으로 표시한다. 원문의 기간 표기에 적용 연도가 없으면 올해 운영기간으로 추정하지 않는다.

## 표시·성능·검증

장소 상세·지역 목록·검색 결과·지도 팝업에서 공통 자료를 사용한다. 사진의 출처·이용 조건·미상 촬영일을 함께 표시한다. 사진은 지연 로딩하고, 홈에서는 대용량 사진 자료 모듈을 내려받지 않는다. 장소 탐색을 열 때만 별도 모듈을 불러오며 실패해도 기본 장소·로그인·GPS 처리는 계속 동작한다.

`tests/place-enrichment.cjs`는 953개 장소의 동일성 조건, 841개 사진의 무변경 해시·크기·이용 조건, 441개 동반 원문 보존, 크기·실내 미확인, 설명 수정 후 조건 연결 해제, 동시 로딩 중복 방지를 검사한다. 기존 가입 포인트·로그인·지도 검색·산책 시작 관련 검사도 함께 실행한다.
