# 지도 탐색 UI

- `map-premium.css`는 주 지도 화면의 단일 스타일 진입점이다. 홈·산책 기록 지도는 변경하지 않는다.
- `map-explorer.js`는 기존 마커를 등록 받아 현재 지도 영역의 목록과 선택 정보창을 만든다. 자체 데이터 조회·좌표 저장·GPS 호출을 하지 않는다.
- PC 결과 패널은 접을 수 있으며 모바일은 목록 또는 선택 정보창 하나만 표시한다. 선택 정보창의 손잡이만 드래그를 처리하여 지도와 내용 스크롤을 보존한다.
- 전문업소는 기존 공유 클러스터와 중복 방지·250개 단위 렌더링을 재사용한다. `onClear`, `onMarkers`, `onReady`는 목록 동기화용 선택 콜백이다.
- 장소 팝업의 기존 출처·사진 이용 조건·전체 동반 안내·상세 링크를 재사용한다. 확인되지 않은 조건은 그대로 미확인이다.
- 코스 선택 때 `CourseRoutes.get`의 출처 대조를 통과한 원래 `path`/`parts`만 표시한다. 분리 구간을 연결하지 않는다. 미확인 코스와 `proposed` 제안 경로에는 선·출발/도착 표시를 만들지 않는다. 기존 217개 경로 중 31개 제안 경로는 정확한 현장 경로로 표시하지 않는다.
- 동일 코스·편의시설·장소 자료 갱신은 마커를 재생성하지 않아 주기적 갱신 뒤에도 선택이 유지된다. 데이터·필터·소유자가 달라지면 갱신한다.

## 2026-10-23 검증

- 홈 구간 HTML이 작업 시작 main과 동일함을 대조했다. DB·인증·산책 GPS 기록 로직 및 데이터 파일은 변경하지 않았다.
- 로컬 UI: 코스 검색/선택, 실제 경로/미확인 경로, 카페·숙소·병원·편의시설, 마커/목록 선택과 강조, 현재 영역 검색, 정보창 펼치기/접기 확인.
- 320/360/390/430px 모바일, 844px 가로 화면, 1280/1440px PC에서 가로 넘침 없음. 실제 휴대폰의 터치·GPS 수신은 별도 실기기 확인이 필요하다.
- 로컬 도메인의 카카오 외부 장소 검색은 제공자 연결 실패 안내를 확인했다. 등록 장소 검색은 계속 사용할 수 있다. 운영 도메인에서 별도 확인한다.
- 테스트 중 발견된 RSS 생성의 Windows 줄바꿈 차이만 정규화해 동일 콘텐츠를 다시 생성하지 않도록 했다. 피드 내용·SEO URL은 바꾸지 않았다.
