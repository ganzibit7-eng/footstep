# 탐색과 화면 구성 개선 — 2026-10-09

공식 사이트에서 확인한 탐색 구조와 디자인 설명을 발자국에 맞게 해석한 자체 디자인이다. 방문·가입·구매 전환의 상승을 측정하거나 사이트 순위를 평가한 작업은 아니다.

| 참고 | 확인한 내용 | 발자국 적용 |
| --- | --- | --- |
| [Airbnb](https://www.airbnb.com/) | 목적지 중심 검색, 서비스별 탐색, 주제별 추천 진입 | 코스·동반장소·기록 바로가기와 사진 중심 카드 |
| [AllTrails](https://www.alltrails.com/south-korea/easy) | 지역·도시·난이도·코스 특성·이용 조건별 탐색 | 검색·난이도·산책 시간을 한 패널에서 선택 |
| [Linear](https://linear.app/now/how-we-redesigned-the-linear-ui) | 메뉴·탭·패널의 시각적 소음을 줄이고 정렬·계층을 일관되게 유지한다는 디자인 설명 | 한국어 글꼴·버튼·선택 상태·테두리 통일 |
| [Aesop](https://www.aesop.com/) | 카테고리별 발견과 사진·제목·짧은 설명으로 구성한 소개 | 간결한 정보와 여백을 사용하는 자체 카드 구성 |

`experience.css`는 메인 앱의 공통 디자인을 담당한다. 홈의 기존 산책 배경과 로고는 유지하며 본문과 제목의 가독성, 메뉴 선택 표시, 상품·코스 사진 카드, 지도·기록·제안·상세 화면의 표면을 정리한다. 모바일에는 코스 정렬을 한 줄로 표시하고 충분한 터치 크기와 작은 화면의 줄바꿈을 제공한다. 어두운 테마와 동작 줄이기 설정을 고려한다.

기존 입력·버튼 ID와 데이터 처리 함수를 유지한다. 찜 버튼은 난이도 이벤트 위임 영역 밖에 두어 찜 클릭이 난이도 선택으로 처리되지 않도록 한다. 상세 필터의 선택 개수는 실제 해당 영역에 있는 태그 조건만 집계한다. 사진 출처·동반 조건·시간 추정 기준·산책 기록의 화면 잠금 제한·제휴 상품 수수료 안내를 보존한다.

검증 및 실제 적용 화면은 배포 후 추가한다.
