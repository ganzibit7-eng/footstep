# 트립닷컴 숙소 연결

2026-10-22 파트너스 로그인 화면의 공식 호텔 검색·제휴 링크 생성 도구에서 발급한 링크만 사용한다. `trip-stays.json`의 공개 추적값은 비밀 인증키가 아니다. 임의 숙소 ID·제휴 ID 생성이나 검색 결과 전체를 특정 숙소 예약으로 연결하지 않는다.

현재 연결: 레스케이프(호텔 ID 19631550), 여수 유탑마리나(42693130). 실제 트립닷컴 숙소명·주소 및 숙소 규정의 반려동물 허용 안내를 대조했다. 레스케이프는 요청 시 동반·별도 요금, 유탑마리나는 동반 가능·별도 요금 안내를 확인했다. 발자국의 기존 관광자료 체중·견종 조건은 보존하며 예약 가능한 모든 객실이 펫 객실이라는 의미가 아니다.

홈은 기존 숙소 상세 링크를 유지하고 확인된 카드에만 보조 예약 링크를 둔다. 숙소 섹션 카드 앞에 수수료 안내를 표시하고 카드에는 제휴 예약임을 표시한다. 상세 페이지는 예약 버튼 바로 위에 전체 수수료 안내를 표시한다. 버튼의 `sponsored noopener noreferrer`와 새 창 동작을 보존한다. 제휴 예약에 이용자의 계정·위치·가입정보를 전달하지 않는다. 별도 Trip.com 추적 스크립트나 자동 이동은 사용하지 않는다.

표시 문구: “발자국은 트립닷컴 제휴 활동으로 예약 실적에 따른 수수료를 지급받습니다.”

- 공정거래위원회 추천·보증 심사지침: https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000249484 (2024-12-01 개정; 미래·조건부 경제적 대가와 명확한 공개 원칙)

후속 숙소는 같은 절차로 대조하고 공식 링크를 발급한 뒤 추가한다. 홈과 기존 정적 상세를 함께 갱신하고 `scripts/generate-seo.mjs`의 `tripBooking(item.id)`를 유지해 자동 재생성 시에도 링크가 보존되도록 한다. 가격·재고·평점은 동기화 근거 없이 복사하지 않는다. 실제 수익 귀속·정산은 Trip.com의 인정 예약 및 파트너스 보고서로 확인한다.
