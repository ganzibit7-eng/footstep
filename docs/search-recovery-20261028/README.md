## 확인된 기술 문제와 수정

1. **사이트맵 날짜 누락:** 기존 생성기는 사진이 있는 장소에서 본문이 바뀌어도 자료 수집일을 우선해 lastmod를 유지했다. 공통 생성기에 전후 콘텐츠 지문을 연결했다. 제목/본문/메타/구조화자료/이미지/출처·내부링크 변화는 실제 생성일, 스타일·JS 캐시키 또는 내용 동일 재생성은 기존 날짜다. 과거 개편일을 추측해 오늘로 소급하지 않았다. 정적 홈의 이번 업데이트 날짜는 명시적으로 반영했다.
2. **동명 전문업소 검색 제목:** 같은 이름·광역·업종인1,331묶음의 제목이 중복됐다. 기존 공개 주소 중 필요한 시군구/읍면/도로명·번호로3,803개 제목과OG제목을 구분했다. 가짜 지점명·후기·운영정보를 만들지 않았으며 페이지 주소·본문·구조화자료는 바뀌지 않았다. 전수 결과 중복제목0이다. 이 디렉터리는10/20~22 추가돼10/16 급감의 직접 원인으로 보지 않는다.
3. **HTTP 진입:** 일반HTTP 요청이200을 반환하고 HTTPS로 강제 이동하지 않는다. HTTPS canonical·www이동은 정상. GitHub Pages 설정 로그인 대기이므로 강제 HTTPS 수정 완료로 보고하지 않는다.
