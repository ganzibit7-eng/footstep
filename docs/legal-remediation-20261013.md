# 발자국 개인정보·구조 보완 확인서

확인일: 2026-10-13(대한민국 시간). 운영자 답변: 미등록 개인 운영 김도윤, Supabase Free, 위치정보 신고·등록·면제 검토 이력 없음, 만 14세 이상 가입.

## 완료 범위

- 운영자·보호책임자·이메일·전화번호를 개인정보처리방침에 명시. 약관과 처리방침 전문은 별도 주소에서만 제공하고 기존 `#privacy`·`#terms` 주소를 해당 페이지로 연결.
- 약관 동의, 만 14세 이상 자기 확인, 회원 개인정보 수집·이용 동의를 분리. 생년월일·신분증·본인확인 자료를 추가 수집하지 않음. 기존 회원의 나이를 검증한 것은 아님.
- 기기 GPS 기록, 선택적인 주변 코스 집계, 계정의 서버 경로 저장을 구분. 기본 선택 해제. 주변 집계는 계정 ID·코스 ID·시각만 전송하며 위도·경도 필드는 NULL.
- 관리자 마크업·스타일·처리 코드와 관리자용 의존성은 지연 로딩. 서버 `getUser`와 `is_admin` 검증을 자원 로딩 전후에 실행. 세션 변경·권한 거절 시 화면을 만들지 않음. 정적 파일 자체의 URL 접근은 가능하며 실제 비공개 자료는 서버 권한으로 제한.
- 방문자 현재 접속·산책 활동은 5분 경과 후 분 단위 정리. 방문 통계 원본은 90일 경과 후 매일 정리(한국 시간 03:45). 기존 제휴 클릭 90일·보안 사건 30일 정리 작업 유지.
- 개인정보 DB 리전 서울, 공개 프로필은 ID·닉네임·배지·사진·시각만 포함. 공개 프로필에 이메일·등록 지역·반려견 정보·GPS 경로는 없음. 기존 로그인, 계정 삭제, RLS, 회원 관리 RPC, 코스 데이터는 유지.

## 운영자가 처리해야 하는 미완료 항목

### 위치정보 사업 유형 및 의무

개인 운영 또는 원본 좌표를 집계 서버에 보내지 않는다는 이유만으로 면제라 판단할 수 없음. 계정에 연결한 산책 경로 저장과 인근 코스 ID도 검토 대상. 위치정보지원센터에 아래 사실을 제시하여 개인위치정보사업 등록 또는 위치기반서비스사업 신고 해당 여부, 소상공인 등 예외의 자격·절차, 법정 동의·약관·이용제공사실 확인자료 보관 의무를 확인해야 함. 신고를 대신 제출하거나 면제 판정을 받은 상태가 아님.

상담자료:

1. 브라우저 GPS를 사용자 동의·권한 허용 후 수신. 경로는 기기에서 계산하고 미저장 초안을 기기에 저장.
2. 사용자가 서버 저장을 선택하면 계정 ID와 경로·시각·거리 등을 서울 Supabase DB의 본인 기록에 저장. 관리자 접근은 운영 권한에 따름.
3. 집계 참여를 별도로 선택하면 계정 ID·인근 코스 ID·갱신 시각을 서버에 전송. 원본 좌표는 NULL. 공개 코스별 인원 합계만 제공. 마지막 갱신 후 5분 경과 시 분 단위 정리.
4. 지도·장소 검색·날씨 조회는 외부 제공자에게 조회 영역·좌표·검색어·접속 정보가 전달될 수 있음.
5. 서비스는 무료, 광고·쿠팡 제휴 수익 구조가 있음. 미등록 개인 운영. 14세 미만 가입은 허용하지 않고 연령 자기 확인으로 제한함.

확인 경로: [위치정보지원센터](https://www.lbsc.kr/) (LBS@kcup.or.kr, 02-588-0185), [정부24 신고 안내](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=15701000085). 운영자의 주소·사업 관련 증빙 및 신고 유형 확정 후 필요 서류를 제출. 신고·등록 완료 전 ‘법적 의무 충족’, ‘신고 면제’ 등 표시 금지.

### 국외 이전·백업·공급자 계약

공식 공개 문서와 확인한 리전은 처리방침에 반영했으나 제공자별 실제 계약 수신 범위·국외 이전 법적 근거·Free 복구 복사본 잔존기간은 확인 완료로 보지 않음. Supabase의 서울 DB가 지원·운영까지 국내 한정이라는 주장을 하지 않음. 수신국·실제 항목·연락처·시점·전송 방법·목적·보관기간·거부 방법을 계약 기준으로 확정하고, 필요한 별도 이전 동의를 적용해야 함.

Supabase 공식 백업 안내의 유료 플랜 복구 기간은 Free의 보관기간으로 옮겨 적지 않음. 새 개인정보 백업을 만들거나 유료 플랜 전환 시 복구 시 재삭제 절차·자동 만료를 정하고 정책을 먼저 개정해야 함. 이번 작업은 개인정보 DB 덤프나 사용자 파일 백업을 생성하지 않았음.

[Supabase 백업](https://supabase.com/docs/guides/platform/backups), [처리 계약](https://supabase.com/legal/customer-resources/data-processing-addendum), [2026-10-12 재위탁 목록](https://supabase.com/legal/subprocessor-list/October-12-2026.pdf).

이메일 문의 처리 완료 후 6개월 삭제는 운영자의 수동 업무 기준이며 메일함 자동 삭제를 설치하거나 실제 과거 메일을 삭제한 것은 아님. 문의 종료일과 파기 상태를 운영자가 기록해야 함.

### 추가 발견: 날씨 API 사용 조건

[Open-Meteo 공식 약관](https://open-meteo.com/en/terms)은 광고가 있는 사이트를 상업적 사용으로 분류하고 Free API를 비상업 용도로 제한함. 현재 광고·제휴가 있는 발자국의 사용권이나 유료 구독 여부를 확인해야 함. 비용 발생 구독을 대신 체결하지 않았고 날씨 기능을 임의 제거하지 않았음. 구독 또는 허용되는 다른 데이터 공급자를 선택하면 별도 연동이 필요함.

## 검증의 한계

GPS는 모의 위치로 검증하며 실기기 잠금·앱 전환은 확인하지 않음. 브라우저 체크박스는 연령 자기 확인·기능 이용 선택이며 법정 본인확인이나 서버의 전 가입 경로를 차단하는 연령 인증을 뜻하지 않음. 법적 적합성 최종 판단·신고 접수·공급자 계약 확인은 운영자와 공식 담당기관·전문가 확인이 남음.
