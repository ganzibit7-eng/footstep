# 운영자 동반 불가 제보에 따른 공개 중단

2026-11-07 사용자에게 전달된 업소 측 요청에 따라 `gocamping_8099`(대구 달성군 옥포로111길 85-6)의 반려견 동반 장소 소개를 내렸다. 동명이 아닌 해당 ID·주소 한 곳만 대상으로 했다.

- DB 공개 상태를 `approved`에서 `rejected`로 변경하고 공개 조회 0건 확인. 관리용 비공개 처리 기록은 보존했다.
- 상세 HTML, 검색 데이터, 추천·지역 목록, 사이트맵의 해당 항목 제거.
- 장소 소개·동반 조건·사진 및 갤러리 연결을 공통 자료에서 제거.
- 공개 일괄 등록 SQL과 과거 등록·보강 자료에서 해당 장소를 제외해 재사용 시 재등록 방지.
- 동반장소 4,169→4,168, 통합 반려생활 장소 21,864→21,863으로 실제 자료와 대조. 홈은 숫자와 집계 기준 설명만 갱신하고 기존 디자인을 보존했다.
- 사용하지 않는 이전 검색 스냅샷 두 개를 정리해 기존 배포 용량 안전 한도 유지. 현재 검색 전체 범위는 4,618건이다.
- 서비스 워커 셸 버전 `v248-place-withdrawal`로 갱신.

저장소 과거 커밋과 외부 검색엔진 캐시를 소급 삭제하지 않았다. 사진 저장소의 원본 객체를 물리 삭제한 것으로 보고하지 않으며, 발자국 공개 화면의 사진 연결을 제거한 작업이다.

검사: 철회 장소 상세·공개 검색·사이트맵 부재 검사, 집계 일치 검사, 전체 회귀 검사. 운영 배포 후 해당 상세 URL의 404와 현행 검색 데이터에서의 제외 여부를 별도로 확인한다.
