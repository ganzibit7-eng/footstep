# 2026-10-03 산책로 자료 검토

47개 추가: 두루누비 원본 GPX 27개, OpenStreetMap의 실제 연결 보행로로 구성한 제안 코스 20개. 반려견 동반은 한국관광공사 또는 시설 운영기관·지자체의 문서로 확인했다. 현장 답사 인증이 아니다.

review.json.gz는 원본 안내 데이터, 동반 조건, 좌표와 GPX 해시 또는 OSM 노드·웨이 ID를 보존한다. GPX 분리 구간은 연결선을 만들지 않는다. 공식 거리와 좌표 계산 거리는 설명에서 구분한다. 기존 서리풀·여의도 코스와 중복되는 제안, 일부 허용 구역을 특정하지 못한 곳, 공사 범위를 확정하지 못한 곳은 보류했다.
