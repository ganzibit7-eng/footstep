# 산책·걷기 경로 300개 확장 검토 (2026-10-04)

공개 경로 217개에 중복 없는 83개를 추가한다. 기존 코스와 사용자 소유 데이터는 변경하지 않는다.

- 6개: 한국관광공사 자료에 장소 전구역 동반 안내가 있는 곳의 OSM 야외 보행로 제안. 공식 지정 코스와 구분하고 난이도는 임의 지정하지 않는다.
- 77개: 두루누비 공식 GPX 경로. **반려견 동반 조건은 미확인**이며 목록·상세 화면에 표시한다. 홈페이지·지도·몽이의 자동 추천에서 제외한다. 전체 목록에서는 걷기 경로로 탐색할 수 있다.
- GPX 후보 150개 중 원본 좌표, 단일 연결 구간, 한국 내 좌표, 최대 좌표 간격 220m, 안내 거리 대비 계산 거리 70–130%, 공식 양 끝 좌표와의 일치 및 기존·신규 코스 중복을 검토했다. 연결되지 않은 좌표 사이에 선을 새로 만들지 않았다.
- OSM 후보 장소 160개를 검토했다. 이름 또는 등록 위치가 일치하는 지도 경계 안의 연결 보행로만 제안했다. 사유지·출입 금지·반려견 금지 태그는 제외했다. 각 인접 좌표는 실제 원본 웨이의 연속 노드이며 도로 교차점은 공유 노드로만 연결했다.
- 일부 행의 자료를 확인한 날짜는 현장 방문이나 당일 운영 확인을 뜻하지 않는다. 공식 GPX가 존재해도 현재 통제·공사·시설별 동반 조건은 달라질 수 있다.

`routes.json`에는 출처 식별자, 원본 GPX SHA-256, 표시한 원본 좌표와 OSM 노드·웨이 및 동반 안내 근거를 보존한다. 장문 관광 소개와 출처 사진은 복사하지 않았다. 사진이 없는 새 경로에는 다른 장소 사진을 붙이지 않는다.

두루누비 GPX의 외부 활용 안내: https://www.data.go.kr/data/15101974/openapi.do
