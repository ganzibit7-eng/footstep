# 공개 산책코스·동반장소 반려견 동반 전수 점검

2026-11-11에 공개 승인 상태였던 산책코스 418개와 동반장소 4,221곳을 대상으로 했다. 별도 전문업소와 배변봉투함은 동반장소 집계에서 제외했다.

| 분류 | 산책코스 | 동반장소 |
| --- | ---: | ---: |
| 조사 시작 시 공개 승인 | 418 | 4,221 |
| 공공 자료·운영기관 안내에서 동반 근거 확인 | 417 | 3,775 |
| 현재 안내에 동반 불가 명시 | 0 | 4 |
| 공식 자료 상충 | 0 | 37 |
| 허용 범위·대상 식별·공식 근거 미확인 등 | 1 | 405 |
| 공개 보류 합계 | 1 | 446 |

식품안전나라에서 동일한 상호와 주소를 대조했고, 고캠핑의 970개 등록번호는 현재 상세 페이지의 상호·주소·출입 항목·상세 소개를 확인했다. 한국관광공사 국문 여행 상세와 개방 관광정보의 반려동물 항목을 재조회했다. 지자체와 운영기관 안내는 실제 산책 구간이나 이용 장소와 연결되는 경우에만 적용했다. 숙소의 야외 공간에 대한 정보만으로 동반 투숙을 확인하지 않았다. 공식 자료에 출입 구역·체중 등 세부 기준이 없으면 그 조건은 미확인 상태다. 자료 조회일은 현장 점검일 또는 사업자 확인일과 다르다.

- 금산 자연 오토캠핑장과 무지개캠핑장은 고캠핑 출입 항목이 불가능으로 표시된다. [금산 자연 오토캠핑장](https://gocamping.or.kr/bsite/camp/info/read.do?c_no=100472), [무지개캠핑장](https://gocamping.or.kr/bsite/camp/info/read.do?c_no=8065)
- 레스케이프는 운영사 소개와 체인 예약 FAQ가 서로 다르다. 홈 카드와 제휴 예약을 제외하고 이미 발자국에 등록된 리센 오션파크 호텔의 지정 동반 객실을 안내한다. [조선호텔앤리조트](https://www.josunhotel.com/hotel/lescape.do), [메리어트 호텔 FAQ](https://www.marriott.com/en-us/hotels/sellm-lescape-a-luxury-collection-hotel-seoul-myeongdong/overview/), [리센 오션파크 호텔](https://api.visitkorea.or.kr/#/hubTourSearchCatDetail?contentId=2910876&langDiv=KOR)
- 포천 한탄강 1코스 구라이길은 반려견 금지 교량과 발자국 등록 경로의 중첩을 확정할 수 없어 공개 보류했다. [한탄강 세계지질공원 구라이길 안내](https://hantangeopark.kr/bbs/content.php?co_id=trail_01_11)
- 프레이저 센트럴 서울과 여수 유탑 마리나는 각각 12kg 미만과 10kg 미만으로 수정했다. 오크우드 프리미어 인천은 운영사의 펫 패키지를 안내하고 현행 기준을 확인할 수 없는 체중과 요금을 표시에서 제외했다. [프레이저 센트럴 서울](https://fpcs.co.kr/faq/faq), [유탑 마리나](https://www.utopmarina.com/about/faq), [오크우드 프리미어 인천](https://booking.oakwoodpremier.co.kr/?hotelCode=opi&lang=ko)

개별 판정과 자료는 [decisions.jsonl](decisions.jsonl)에 보존했다. 보류 상태는 Supabase의 기존 pending으로 전환하며 원본 좌표·사진·콘텐츠를 보존한다. 검색 페이지 생성기는 별도 공개 제외 목록을 적용한다. 나중에 재공개할 때는 동일 지점·구간과 최신 동반 정책의 근거를 기록하고, 해당 ID만 공개 제외 목록에서 제거한 뒤 승인 및 정적 페이지 재생성을 검증한다.

전남은 공개 기준을 충족한 코스 27개와 동반장소 2곳을 기존 지역 안내 주소에서 계속 제공한다. 운영 데이터와 생성 결과는 동일한 ID 목록으로 확인한다.
