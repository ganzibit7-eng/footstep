# 공식 경로 추가 조사 (2026-10-02)

서울시 150개 걷기길 목록에서 기존 자료에 없던 34개 상세 안내와 지도 좌표를 대조하고, 두루누비 해파랑길 50개 코스 목록 및 반려견 테마 자료를 추가 조사했다. 현장 답사가 아니라 공식 문서와 공개 좌표 확인이다.

## 반영: 8개 (116 → 124)

- c334 서울숲 남산길 응봉근린공원 구간: 서울시 지도 원본 179좌표. 기존 매봉산공원 CC BY 사진 공유.
- c335 서울 진경산수화길: 서울시 지도에서 분리된 세 구간을 각각 유지. 사진 미확보.
- c336 서울 지양산 둘레길: 서울시 제공 지도 좌표만 사용. 공식 전체 안내 4km와 지도 표시 구간의 차이를 명시. 사진 미확보.
- c337 양양 낙산해변: 해파랑길44 GPX의 100~175번 좌표. 낙산사 내부 제외.
- c338 속초 대포항: 해파랑길45 GPX의 0~60번 좌표.
- c339 속초해변: 같은 GPX의 120~210번 좌표. 외옹치 데크 제외.
- c340 속초 아바이마을: 같은 GPX의 230~275번 좌표. 갯배 이용 조건 확인 안내.
- c341 속초 영랑호 호반: 같은 GPX의 440~730번 좌표. 호수 전체 순환 코스가 아닌 선택 구간.

좌표 번호는 원본 trkpt 기준 0부터 시작한다. 잘라낸 구간의 좌표를 추가하거나 보간하지 않았다. 거리는 각 원본 좌표 사이 구면거리의 합계이며 공식 전체 코스 거리와 구분한다. 해파랑길 일부구간은 별도 공식 지정 코스라고 주장하지 않는다. 사진의 장소는 해당 산책 구간의 명소이며 모든 지점의 현재 상태를 보증하지 않는다.

## 제외 / 보류

북한산 구름정원길은 서울시의 오래된 반려견 안내와 국립공원 출입 제한이 충돌하므로 제외했다. 서대문 북한산 자락길도 경계와 출입 조건이 불확실하여 보류했다. 해파랑길45 전체는 공식 안내에 외옹치 바다향기로 및 속초등대 통제 공지가 있으므로 공개하지 않았다. 새만금 반려견 테마길은 유지관리 문제, 요천 테마길은 위치 데이터 불일치를 발견하여 보류했다. 반려견 동반 근거 또는 실제 경로가 없는 다른 후보는 추가하지 않았다.

신규 8개 중 6개에 실제 장소 사진을 제공한다. 전체 사진 적용 코스는 94 → 100개, 고유 사진은 84 → 89장. 미확보 사진은 임의의 다른 장소 사진으로 대체하지 않는다.
