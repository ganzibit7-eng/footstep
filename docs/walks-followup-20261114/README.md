# 2026-11-14 산책코스 후속 공개

공개 코스 548곳에 신규 보행 구간 5곳을 추가한다. 한국관광공사의 장소별 반려동물 동반 자료와 지자체 공개 안내를 대조했다. OpenStreetMap의 연속된 보행 노드만 사용해 거리를 계산했다. 현장 답사와 공식 GPX가 없는 경로는 공개 보행로 기반 제안 경로로 표시한다.

| 코스 | 지도 표시 거리 | 보행 근거 |
| --- | ---: | --- |
| 화성 궁평항 북쪽 해안 산책로 | 0.37km | [화성시 황금해안길](https://tour.hscity.go.kr/NEW/9gold/gold1.jsp) |
| 울산 태화강 십리대숲 산책로 | 0.56km | [울산시 국가정원 안내](https://www.ulsan.go.kr/s/garden/contents.ulsan?mId=001004004000000000) |
| 서울 낙산공원 안쪽 산책로 | 0.26km | [서울시 낙산공원 안내도](https://parks.seoul.go.kr/maps/naksan/naksan_map_KR%26CN.pdf) |
| 서귀포 쇠소깍 동쪽 야외 산책로 | 0.40km | [제주관광공사 하효 산책 안내](https://www.visitjeju.net/kr/detail/view?contentsid=CNTS_300000000012862) |
| 경주 감포항 북쪽 육상 산책로 | 0.25km | [경주시 감포항 안내](https://www.gyeongju.go.kr/tour/page.do?mnu_uid=4701) |

사진은 공공누리 제1유형 5장이다. 같은 사진을 두 번 배포하는 일을 줄이기 위해 기존 장소 사진의 검증된 웹용 파일 4개를 재사용한다. 낙산공원 코스는 기존 순성길과 같은 지점으로 연결되나 지도상 12m 범위에서 겹치는 길이는 약 20%이며 전 구간은 공원 내부로 제한했다. 궁평항 코스는 이미 공개된 궁평 해송숲 코스와 별도 구간이다.

전국 112개 검색어와 이전 후보를 함께 검토했다. 여수 장도는 [여수시 안내](https://www.yeosu.go.kr/tour/travel/info_each_area?idx=501&mode=view) 내 반려견 안내가 상충한다. 선납숲공원은 일부구역 동반과 여러 이동 조건이 함께 기재되어 구역별 적용 규칙이 명확해질 때까지 보류했다. 민락수변공원과 삼척장미공원은 확인된 일반 보행로의 구역과 연결 상태를 추가로 대조해야 한다. 서초 길마중 초록숲길은 구청에서 동반과 경로를 안내하고 있으며 재사용 가능한 실사진 근거를 추가로 확인해야 한다.

피아노폭포는 버스 정류장 접근 안내, 고객 전용 보행자 통로, 생태공원 자료를 다시 확인했다. 방문객 입구에서 관람 지점까지 이어지는 노선을 확인하지 못해 현재 위치 안내를 유지한다.
