# 2026-11-13 지역 산책코스 보강

공개 코스 452곳을 기준으로 한국관광공사의 전국 관광·반려동물 자료, 지역별 공식 관광 검색 및 지자체·운영기관 안내를 교차 확인했다. 등록된 장소명과 좌표를 대조하고, 같은 장소에서 찍은 공공누리 제1·3유형 사진과 반려견 동반 보행 범위를 모두 확인한 46곳을 한 번에 반영한다. 공개 코스는 498곳이다. 확인일은 문서 확인일이다.

- 부산시 금강댕길은 지정 표지 구간, 서울 보라매공원은 일반 야외 보행 구역, 인천 청라호수공원은 동반 수칙 안내가 있는 호숫가 보행로를 안내한다. 제주관광공사 자료로 도두봉, 이호테우해변, 금오름 및 생각하는 정원 수칙을 대조했다.
- 시흥 갯골생태공원 프로그램·캠핑장은 제외했다. 양양 낙산해변은 개장 중 D구역만 동반할 수 있고 반려견은 입수할 수 없다. 청산수목원은 10kg 이하이며, 구곡폭포는 동물등록 및 견종·행동 제한이 적용된다.
- 보라매공원과 청라호수공원 2곳에 OpenStreetMap의 연결된 공개 보행로를 제안 경로로 수록했다. 나머지는 대표 위치와 이용 범위를 표시한다. 금강댕길의 1km는 부산시 공개 안내의 길이이며 지도 핀은 공원 대표 위치다.
- 코스별 동반 원문과 사진별 권리·원본 주소를 `batch.json`에 기록했다. 제3유형은 JPEG 원본과 전체 비율을 보존했다. `photo-delivery.json`은 기존 사진 서버와 바이트가 동일한 원본의 연결 근거다.
- 용눈이오름은 기존 코스와 중복됐다. 산방산 둘레길은 동반 가능한 바깥길 사진을 확보해야 하고, 명파해변은 개방 범위를 추가 확인해야 한다. 대표 보류 이유는 `batch.json`에서 확인할 수 있다.
