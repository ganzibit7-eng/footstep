# 동래이층 방문 정보 정정 · 2026-11-23

- 대상은 부산 동래구 명륜로 145의 동래이층 비스트로다. 기존 장소 ID, 주소 원본, 좌표, 공개 URL을 보존했다.
- 매장이 작성한 [당근 비즈프로필](https://www.daangn.com/kr/local-profile/%EB%8F%99%EB%9E%98%EC%9D%B4%EC%B8%B5-b1r2kui2f7im/)에서 실내 홀·야외 테라스 동반, 매너벨트, 평일 영업, 주문 마감, 주차 지원, 예약, 난방이 있는 2~6인 돔텐트를 확인했다. 토요일 시간과 매장 전화는 [테이블링 매장 정보](https://www.tabling.co.kr/restaurant/11710)와 대조했다. 매장이 안내한 [네이버 플레이스](https://m.place.naver.com/restaurant/1142664073)를 연결했다.
- 견종·체중은 자료 간 차이가 있어 방문 전 매장 문의로 남겼다. 실내 자유 이동을 보장하는 안내는 넣지 않고 [식약처 음식점 이용 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148960462)에 맞춰 현장 안전수칙을 안내했다. 확인이 어려운 단체 최대 인원과 돔텐트 이용시간은 예약 시 문의로 안내했다.
- 기존 정적 생성기와 지도 공통 조건 표시에서 같은 장소와 원본 자료가 일치할 때만 새 운영 안내를 적용한다.
