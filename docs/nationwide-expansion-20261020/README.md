# 전국 신규 동반장소와 실제 보행 경로 — 2026-10-20

공개 기준 코스 407개·동반장소 3,133곳에서 시작했다. 국문 관광 자료 49,607건과 반려동물 동반 여행 목록 601건을 대조해 기존 장소를 제외했다. 동반 관련 후보 1,277건 중 행사·쇼핑 등을 제외한 1,235건의 현재 구조화 동반 자료를 조회했고, 별도로 소개에 동반 허용 표현이 있는 535건의 현재 공개 상세와 개별 사진 이용 유형을 검토했다. 단순 지명 일치·근처 장소·기존 이름 변형·보호구역 범위 불명확·동반 부정 문장·미세 구역 제한이 해소되지 않은 후보는 보류했다. ‘동반할 수 없다’를 허용으로 분류하지 않도록 부정 표현도 별도로 검사했다.

새 동반장소 539곳에 사진 539장(256,925,815바이트)을 연결했다. 사진마다 Type1/Type3의 상업적 재사용 가능 여부·해시·원본 크기·장소 contentId를 보존했다. 전체 비율과 제공 파일을 유지한다. 화장실·개수대·소품 위주의 대표 사진은 다른 공식 사진 15장으로 교체했다. 금곡공원은 원본이 지나치게 크고 제공 작은 사진은 150×100에 불과해 이번 등록에서 보류했다. 사진 파일은 장소 공개 전에 먼저 배포했다.

100곳은 현재 구조화 동반 구역·견종·준비물·추가 제한 원문을 보존했다. 439곳은 현재 공식 관광 소개에 동반 가능이 명시돼 있으나 구조화 조건은 없어 `introAllowance`로 따로 구분한다. 소개를 ‘전구역 동반 가능’이나 ‘전 견종 허용’으로 승격하지 않는다. 이들 장소의 견종·체중·준비물·실내 출입은 별도 확인이 없으면 미확인이다. 정원·테라스 등 허용 문맥과 조건을 함께 표시한다. 소개 확인일은 운영정책 갱신일이나 현장 방문일이 아니다. 주소·좌표·설명이 바뀌면 소개 근거도 연결되지 않도록 제한한다.

산책 코스는 실제 경로 기준으로 구영공원 약 0.34km·미사한강공원2호 약 0.70km의 2개를 준비했다. 262개 동반 근거 후보를 공개 지도 공원 경계·보행로와 대조했다. 기존 공원과의 중복, 300m 이상의 연속 보행로 미확인 후보는 추가하지 않았다. 두 경로는 OSM 원본의 인접 노드·웨이만 연결한 **지도 기반 제안 경로**이며 공식 지정 코스나 현장 답사가 아니다. 두 경로 전체가 해당 공원 경계 안에 있음을 공간 연산으로 확인했다. 기존 407개 경로의 25m 주변과 10% 이상 겹치는 경로는 없었다. 사유·고객 전용·보행 금지·반려견 금지·실내 경로를 제외했다. 선택 경로 양 끝은 정문·주차장으로 확정하지 않고 공원 대표 주소와 구분한다. 계단·경사·쉼터·난이도·현재 통제는 미확인이다.

동반 근거는 해당 공원에 관한 공식 소개의 동반 가능 안내이며 전 구역 무제한 허용이라고 표시하지 않는다. 구영공원의 목줄·배변봉투 조건을 보존한다. 미사한강공원2호의 견종·체중·준비물 세부 기준은 미확인이다. 놀이·체육·수경·실내 시설의 별도 출입 허용을 뜻하지 않는다. 사진은 해당 공원의 실제 경관 참고사진이며 전체 경로 사진이 아니다.

준비된 공개 대상 합계는 코스 409개·동반장소 3,672곳이다. 사진 보유는 1,783곳, 사진 연결 4,725장이다. 처음에는 DB에 pending으로 넣어 공개되지 않도록 했으며, 최종 승인·배포 검증은 별도 결과 파일과 GitHub 배포 결과로 확인한다. 기존 행·회원·로그인·GPS·RLS·계정 권한은 변경하지 않는다. 신규 등록 수는 수동 배포값에만 반영하고 방문자 접속 시 재집계하지 않는다. 홈 공지창을 다시 추가하지 않고 같은 날짜 업데이트 내역에만 요약한다.
