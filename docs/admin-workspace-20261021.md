# 관리자 업무 화면 개편 · 2026-10-21

- 종료된 커피 추첨 관리 화면, 응모 회원 필터, 회원 카드의 응모 표시와 전용 스크립트를 제거했다. 저장된 이벤트 기록 및 데이터베이스 함수는 삭제하지 않았다.
- 운영 개요, 회원 관리, 콘텐츠 검수, 제휴 성과, 보안 기록, 데이터 관리의 여섯 업무 메뉴로 분리했다. 기존 권한·조회·검수 처리 방식을 유지한다.
- PC 측면 메뉴, 모바일 3열 메뉴, 한 열 회원 카드, 개별 가로 스크롤 표를 제공한다. 모바일 입력 글자는 16px, 주요 조작은 44px 이상으로 맞춘다.
- 관리자 자산은 로그인 사용자와 서버 관리자 권한을 확인한 뒤 필요할 때만 불러온다. 재확인·로그아웃 시 폐기·비인가 사용자 무로딩 검사는 유지한다.
- 사용자 홈 공지는 관리자 전용 변경이라 추가하지 않는다.
