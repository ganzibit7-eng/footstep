# 날씨 제공과 상품 카드 보완 — 2026-10-17

## 확인한 문제와 변경

기존 홈은 브라우저가 Open-Meteo 날씨·대기질 주소를 직접 요청했다. 한 번 실패하면 다시 확인할 수 없고 두 응답을 모두 기다린 뒤 그렸다. 갤럭시에서 보고된 개별 실패의 네트워크 원인은 실기기 없이 확정하지 않았다. 또한 기존 무료 API 정책은 광고가 있는 사이트의 사용을 비상업적 용도로 보지 않는다.

날씨는 MET Norway의 공개 예보를 사이트 안의 `data/weather.json`으로 제공한다. 대한민국의 공개 대표 지점 22곳만 서버에서 조회하고 방문자의 IP·계정·등록 위치를 이 제공자에게 전송하지 않는다. 클라이언트는 등록 위치가 유효하면 가까운 대표 지점을, 아니면 서울 기준을 골라 예보 시각·지역·출처와 함께 표시한다. 위치 권한을 새로 요청하지 않는다. 실측 날씨·현장 대기질로 표시하지 않는다.

시간별 예보는 48시간 범위로 보관한다. 현재 시각에서 90분 이내 예보만 골라 표시하며 모델 갱신 후 6시간이 지나면 이전 갱신 자료로 표시하고 36시간을 넘으면 사용하지 않는다. 미래 생성 시각·누락 온도·잘못된 단위도 거부한다. 브라우저의 유효한 저장 사본을 먼저 표시하고 같은 주소의 최신 자료를 확인한다. 6초 연결 제한·다시 확인·연결 복구 후 재시도·중복 요청 방지·다른 지역으로 바뀐 뒤 늦게 도착한 응답 무시를 적용한다. 저장소가 차단돼도 작동한다. 지도·로그인 초기화 실패와 독립적으로 기본 날씨를 불러온다.

대기질은 기존 예측 수치를 더 이상 자동 요청하지 않고 에어코리아에서 직접 확인하도록 연결한다. 날씨 수신 실패 시 기상청 예보 링크도 제공한다.

원자료 중 대표 지점·시각·기온·기상 기호를 추출한 사실과 출처·CC BY 4.0 링크를 카드에 표시한다. 서버 요청은 발자국 User-Agent로 식별하고 제공자의 Expires·Last-Modified를 따른다. 한 시간마다 23분에 공개 예보를 갱신하는 작업은 방문자·회원 데이터에 접근하지 않는다. 갱신본을 저장소에 올린 뒤 동일 저장소 Pages 배포를 요청한다. 실패한 경우 이전 유효 자료를 유지하고 불완전한 최초 결과를 발행하지 않는다.

## 상품 카드

6개 상품과 기존 발급 제휴 URL·이미지·옵션·제휴 고지는 유지한다. 반복 맥락 문구, 카드마다 반복된 확인일·제휴 상품 표기·일반적인 구매 설명을 제거했다. 확인일과 일반 확인사항은 섹션 하단 한 곳에 모았다. 세정제의 반려동물 몸에 사용 금지 안내는 카드에 유지한다. 상품평·구매 표시는 기존 출처·확인일의 30일 유효성 검사를 그대로 적용한다.

PC·태블릿도 한 줄 가로 카드로 구성하고 이전·다음과 키보드 조작을 제공한다. PC는 3장, 태블릿은 2장, 모바일은 다음 카드가 살짝 보이는 폭으로 표시한다. 사진 영역은 156~176px, 버튼은 44~46px이며 상품명은 잘라 숨기지 않는다. 배지는 사진 위에 겹쳐 놓지 않고 사진 영역 안의 별도 줄에 배치해 줄바꿈돼도 이미지와 겹치지 않는다.
