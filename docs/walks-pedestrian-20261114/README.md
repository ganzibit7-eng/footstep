# 2026-11-14 산책코스 추가 검토

5곳을 먼저 배포해 553곳을 확인했다. 지역별 운영기관 자료를 추가 검토해 산책코스 2곳을 공개 대상으로 확정했다.

| 코스 | 지도상 거리 | 동반 범위와 보행 근거 |
| --- | ---: | --- |
| 부산 민락수변공원 갈맷길 산책 | 0.52km | 공원에 접한 야외 보행로만 안내한다. [부산시 갈맷길 2-2구간](https://www.busan.go.kr/galmaetgil/tour0202), [부산시 반려견 산책 구간 자료](https://www.busan.go.kr/yesan/spiritOffer1/1561277?curPage=11&srchBeginDt=&srchEndDt=&srchCtgry=&srchKey=&srchState1=&srchState2=2&srchText=) |
| 서울 반포 달빛광장 세빛섬 앞 산책로 | 0.26km | 달빛광장 육상 보행로만 안내한다. [서울시 미래한강본부 공원 안내](https://hangang.seoul.go.kr/www/contents/663.do?mid=463), [반려동물 동반 안내](https://hangang.seoul.go.kr/www/bbsPost/17/488/detail.do?keyword=all&mid=604&opt1=&pageNo=1&pstOrd=) |

두 곳 모두 공식 안내가 가리키는 보행 구간과 OpenStreetMap의 연속된 노드를 대조했다. 지도에 연결한 두 구간은 공개 보행로 기반 제안 경로다. 출처가 확인된 공공누리 제1유형 사진의 기존 웹용 파일을 재사용하며 전체 구도와 출처를 보존한다. 자료 대조이며 현장 답사는 하지 않았다.

안동 낙강물길공원은 안동댐 공사에 따른 전면 통제 보도가 있어 보류했다. 서초 길마중 초록숲길은 서초구청에서 반려견과 걷는 코스로 안내하지만, 확인한 보도자료 사진이 공공누리 제4유형이어서 사용하지 않았다. 속초 대포항의 동반 정보는 일부 구역으로 안내되어 전망대 접근로 전체에 적용할 수 있는지 확인되지 않았다. 피아노폭포는 시설 입구에서 관람 지점까지 정확한 공개 보행로가 확인될 때까지 위치 안내를 유지한다.
