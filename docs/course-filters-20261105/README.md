# 전국 탐색: 시간·난이도 복합 필터

기준 main 43fbfc02faad5528a8a8339849b3c81d6f9bff0b. 2차 프로젝트의 다음 기능 단위이며 전체 4~10순위 완료가 아니다. 기존 검색 표기·관련성·개별 해제 구현은 재사용한다.

## 범위와 홈 보호
- 사용자의 2026-11-05 최신 지시대로 홈화면을 변경하지 않았다. AGENTS.md에 홈 보호 원칙과 업데이트 공지 예외를 기록했다. index.html과 홈 CSS/JS/애니메이션/데이터는 변경하지 않는다.
- 원천 장소·코스·사진·권리·회원·GPS·지도·DB·권한 변경 없음. 공개 검색 원본4,619개와 코스412개 동일. discover title/meta/canonical/JSON-LD 및 검색 manifest 원문 동일 검사 통과.

## 구현
- place-search.js는 기존 공개 facts의 '공식 안내 시간' 또는 '평지 예상 시간', '등록 난이도'만 읽는다. 거리·이름·경로로 시간을 재계산하거나 난이도를 추측하지 않는다. 공식 시간 우선. 범위 문장/미확인 값은 필터 충족으로 취급하지 않는다.
- 시간 범위는 30분 이하 / 30분 초과~1시간 / 1시간 초과~2시간 / 2시간 초과. 경계 중복 없음. 난이도는 등록 쉬움/보통/어려움.
- 산책코스일 때만 조건 표시·활성화. 다른 종류로 전환하면 코스 조건 해제. URL duration/difficulty 및 기존 q/region/sort/shown 상태 보존. 유효한 시간만 있는 URL은 코스로 진입하고, 업종과 충돌하거나 잘못된 값은 정리한다.
- 선택 요약·개별 제거·빈 결과에서 시간만/난이도만 완화. 전체 초기화 시 모두 해제. 일반 장소 검색·미확인 동반 조건 규칙·기존 분할 다운로드·재시도·뒤로가기 로직 유지.
- 작은 화면(600px 이하)의 기존 2열이 한 결과를 약155px에 가두던 현상을 discover 전용 1열로 보완. 사진 크롭/출처/CTA 구조는 그대로. 홈 카드는 적용 대상이 아니다.
- discovery-layout 공통 생성기에 반영. 재실행 변경0. 검색 자산 버전20261105-course-filters / SW v239-course-filters. 새 라이브러리·검색 화면·분석 수집 없음.

## 데이터 가용성
412개 코스 중 공식 시간116개, 평지 예상105개, 시간 미확인191개. 등록 난이도 미확인212개. 미확인은 전체 검색에서 제외하지 않고 해당 조건을 선택한 경우에만 제외한다. 자료를 새로 검증한 것으로 표시하지 않는다.
