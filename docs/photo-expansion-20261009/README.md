## 검증 범위

- 공공누리 제1유형과 CC BY-SA 공개 사진만 사용. 상업적 이용금지·변경금지 사진, 원본 신청이 필요한 고해상도 파일은 제외.
- 공개된 화면 표시용 파일을 축소·WebP 변환하여 자체 제공. 원본 크기보다 확대하지 않음.
- 발행일과 촬영일을 구분하고 촬영일 미상 자료는 명시. 과거 사진은 현재 현장 상태를 보장하지 않음.
- 호미반도 선바우 사진의 현장 안내판을 직접 확인. 다른 호미반도 구간으로 확대 연결하지 않음.
- 여강길 3코스의 신륵사 입구, 4코스의 강변 산책 사진을 구분. 강천섬 사진은 3-1코스에만 연결.
- 간절곶소망길 4코스의 종점과 5코스의 출발부인 간절곶 사진을 공통 연결. 1코스에는 연결하지 않음.
- 월미산은 광장 전경이라는 캡션과 둘레길 주변임을 표시.
- 출처 표기, 코스 이름·ID 일치, 실제 이미지 디코딩, 정적 상세 페이지, JavaScript 문법, 사진 확대 보기의 출처·포커스 복원 검증.
