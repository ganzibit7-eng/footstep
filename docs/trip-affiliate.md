# 트립닷컴 숙소 연결

2026-10-22 파트너스 로그인 화면의 공식 호텔 검색·제휴 링크 생성 도구에서 발급한 링크만 사용한다. `trip-stays.json`의 공개 추적값은 비밀 인증키가 아니다. 임의 숙소 ID·제휴 ID 생성이나 검색 결과 전체를 특정 숙소 예약으로 연결하지 않는다.

현재 연결: 기존 2곳에서 112곳을 추가해 상세 114개, 홈 10개 카드. 같은 숙소의 자료명 차이로 연결되는 4개 별칭을 포함하며 실제 예약 목적지는 110개다. 공개 숙소 490개 전체를 공식 호텔 검색으로 조회하고, 1차 미검색 대상 중 296개는 축약·띄어쓰기 표기로 재조회했다. 후보 176개의 실제 숙소 페이지를 열어 주소·표시된 규정을 대조했다. 도로명·건물번호가 같은 대상과 사람이 대조한 영문 도로명 표기만 연결했다. 예약 플랫폼에 동반 규정이 없는 대상은 이를 버튼 옆에 명시하며 기존 관광자료 조건을 보존한다. 모든 객실이 펫 객실이라는 의미가 아니다.

전수 검토 기록은 `trip-stays/audit-20261022.json`에 보관한다. 미연결 376개는 동일 판매상품 미검색 259개, 후보 추가 확인 49개, 주소·상품 재확인 54개, 동일 주소이나 예약 플랫폼 동반 안내 재확인 14개다. 미검색은 미판매·폐업을 확정하는 표현이 아니다. 플랫폼 동반 불가는 숙소 자체의 동반 불가로 변경하지 않는다. 펫 전용 객실·패키지나 플랫폼별 안내 차이가 있을 수 있어 예약 연결만 보류한다.

홈은 기존 숙소 상세 링크를 유지하고 확인된 카드에만 보조 예약 링크를 둔다. 숙소 섹션 카드 앞에 수수료 안내를 표시하고 카드에는 제휴 예약임을 표시한다. 상세 페이지는 예약 버튼 바로 위에 전체 수수료 안내를 표시한다. 버튼의 `sponsored noopener noreferrer`와 새 창 동작을 보존한다. 제휴 예약에 이용자의 계정·위치·가입정보를 전달하지 않는다. 별도 Trip.com 추적 스크립트나 자동 이동은 사용하지 않는다.

표시 문구: “발자국은 트립닷컴 제휴 활동으로 예약 실적에 따른 수수료를 지급받습니다.”

- 공정거래위원회 추천·보증 심사지침: https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000249484 (2024-12-01 개정; 미래·조건부 경제적 대가와 명확한 공개 원칙)

후속 숙소는 같은 절차로 대조하고 공식 링크를 발급한 뒤 추가한다. `node scripts/sync-trip-stays.mjs`로 홈과 기존 정적 상세를 함께 갱신하고 `scripts/generate-seo.mjs`의 `tripBooking(item.id)`를 유지해 자동 재생성 시에도 링크가 보존되도록 한다. 가격·재고·평점은 동기화 근거 없이 복사하지 않는다. 실제 수익 귀속·정산은 Trip.com의 인정 예약 및 파트너스 보고서로 확인한다.
