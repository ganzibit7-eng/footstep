## 이번 배포
- Bing 소유 확인 태그, IndexNow 루트 확인 파일.
- 사이트맵 두 개의 공개 대표 페이지 4,338개를 로컬 파일·canonical·noindex·리디렉션 기준으로 검증.
- 정상 배포가 끝나면 변경·추가·삭제한 공개 URL만 IndexNow 글로벌 엔드포인트로 알림. 참여 검색엔진끼리 공유되므로 각각 중복 제출하지 않음.

## 하루 200명에 도달하기 위한 운영 기준
- 목표 지표: 관리자에서 봇·운영자 제외 일 방문 브라우저 수의 7일 평균 200. 검색 클릭·페이지뷰와 구분하고 중복 기기는 합산될 수 있음을 감안.
- 매주 Google/Bing의 검색 노출·클릭·CTR·색인 상태, 관리자 검색엔진별 유입과 지역 페이지 방문을 같은 기간으로 비교.
- 첫 단계는 검색 유입 10명/일, 이후 30→70→200명/일. 날짜를 확정하거나 달성을 보장하지 않음.
- GSC에서 노출이 쌓이는 장소·지역 검색어의 실제 동반 조건·사진·운영기관 출처를 보완. 확인되지 않은 조건은 미확인으로 유지.
- 클릭이 적은 페이지는 검색어와 제목·설명이 맞는지 먼저 점검. 품질이 낮은 페이지를 기계적으로 늘리지 않음.
- 검색 CTR 3%를 가정하면 검색 클릭 200회에는 하루 약 6,667회 노출이 필요함. 예시 계산이며 현재 유입 예측이 아님.
- 외부 홍보는 지역 반려견 커뮤니티에 운영자가 직접 유용한 코스 안내를 공유하고 캠페인 링크로 측정. 본 작업에서 게시·메시지·유료 광고를 진행하지 않음.
