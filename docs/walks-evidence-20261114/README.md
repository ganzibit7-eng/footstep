# 2026-11-14 반려견 동반 산책코스

신규 8곳은 한국관광공사 또는 강원관광재단의 반려견 동반 정보와 OpenStreetMap의 연속된 야외 보행로를 확인했다. 사진은 한국관광공사의 장소별 공공누리 제1·3유형 자료를 시각 대조했다. 기존 경로 미확인 6곳 중 망원한강공원, 소래포구, 푸른수목원, 달빛축제공원, 담양 메타세쿼이아길 5곳을 보강했다. 피아노폭포는 폭포 관람 공간과 외부 길 사이의 보행 연결 근거가 부족해 위치 안내를 유지했다.

공개 보행로는 점선 제안 경로로 표시한다. 지도 거리·시작점·종료점과 공식 동반 출처를 표시하며, 현장 답사는 하지 않았다. 망원은 양화나루길과 다른 짧은 강변 보행로, 소래는 옛 철교와 접근로, 푸른수목원은 항동저수지 서안, 달빛축제공원은 송도동 26-1 보행로, 담양은 포장로로 범위를 한정했다. 각 코스의 좌표·공식 출처·사진별 원본과 제외 사유는 batch.json에 기록했다.

출입 조건과 사진 사용 허락이 기록된 공식 자료 후보 141건을 일차 선별했다. 같은 장소인지를 판별하고, 영업시설·중복 장소·출입 허용 범위를 경로에 결합할 수 없는 곳은 제외했다. 신규 8곳을 반영하면 공개 537곳, 1,000곳까지 463곳이다. 기존 코스와 장소가 공유하는 바이트 동일 사진은 하나의 공개 파일을 사용하고 Git의 원본과 출처는 보존했다.
