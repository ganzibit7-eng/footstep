# 기존 동반장소 사진·조건 보완 — 2026-10-18

기존 공개 승인 장소 3,133곳을 대상으로 보완했으며 신규 장소나 승인 상태를 변경하지 않았습니다.

- 기존 876곳에서 912곳으로 대표 사진 연결 확대(+36곳).
- 제공 원본 사진 1,006장 추가. 총 사진 연결 1,882장(대표 912장·추가 970장).
- 652곳에 사진 더 보기 묶음을 제공하며, 지도·검색 목록은 대표 사진만 표시합니다.
- 공식 반려동물 상세 자료 441곳에서 443곳으로 확대. 공식 관광 소개의 동반 관련 원문 290곳을 별도 출처·대조일과 함께 추가했습니다.
- 자료 상충·제한 재확인 경고는 16곳에서 18곳으로 늘었습니다. 태그하우스·어썸비치는 관광 소개의 동반 불가와 기존 자료가 달라 운영기관 재확인을 안내합니다. 푼타하우스의 반려견 미동반·공격성·질환 제한을 일반 동반 금지로 처리하지 않습니다.
- 이름 변형 후보는 도로명·건물번호 일치, 100m 이내 좌표, 고유 상호 포함 일치로 대조했으며 새 사진이 생긴 장소는 표본 사진 모음으로 추가 검토했습니다.

## 사진·출처

국문 관광정보 서비스: https://www.data.go.kr/data/15101578/openapi.do
공식 자료가 선별 제공하는 사진만 이용했습니다. 원본 바이트·전체 비율·워터마크를 유지하며 사진마다 출처, 이용 조건, 촬영 시기 미상 안내를 표시합니다. 해시·크기·출처를 검사했습니다. 일반 웹사이트·네이버 이용자 사진은 복사하지 않았습니다.

## 용량과 미완료

사진 후보 1,804장을 검증했습니다. 중복·크기·파일 검사를 거친 후 기존 사이트 용량과 배포 한도를 고려해 신규 원본 파일 약 280MB를 반영했습니다. 고용량 후보 798장은 보류했습니다. 변형 금지 가능성이 있어 원본을 임의 압축·자르기 하지 않았습니다. 아직 사진이 없는 기존 장소 2,221곳은 사진을 임의로 채우지 않았습니다.

공식 사진은 해당 콘텐츠의 제공 이미지이며 현재의 시설 상태나 모든 구역의 반려견 출입을 보증하지 않습니다. 조건 자료의 대조일과 정책 변경일을 구분합니다. 회원·로그인·GPS·데이터베이스 스키마는 변경하지 않았습니다.

## 검증

대표·추가 사진 파일 SHA-256, 크기, 라이선스·출처와 동일 장소 결합, 주소·설명 변경 후 조건 연결 해제, 미확인 조건 보존, 조건부 제한 오분류 방지, 추가 사진의 상세 전용 지연 로딩, 키보드 기본 펼치기, 기존 지도·찜·네이버 링크와 검색 구조화 데이터를 검사합니다.
