# 2026-11-13 지자체·운영기관 산책코스 보강

공개 코스 430곳과 이름·위치를 대조하고, 방문할 수 있는 야외 보행 구역의 반려견 동반 근거와 같은 장소의 공공누리 실제 사진을 함께 확인한 22곳을 선정했다. 수록 후 공개 코스는 452곳이다. 각 코스의 자료 확인일은 2026-11-13이며 현장 답사 날짜가 아니다.

- 경주시 문화관광, 화성특례시 관광 안내, 인천투어, 울산시 관광, 제주관광공사, 강아지숲 운영기관 및 한국관광공사의 장소별 반려동물 자료를 대조했다. 평창군 자료는 국민의 숲 트레킹 코스 위치·구간을 대조하는 데 사용했다.
- 경주읍성은 성벽 아래만, 황성공원은 맨발 황토길을 제외한 구역, 대천·무창포는 입수 없이 해변 산책을 안내한다. 상가리야자숲의 10kg 이하와 목줄·매너벨트도 명시했다.
- 용산가족공원, 황성공원, 환호공원 3곳은 공개 지도에 연결된 보행로를 제안 경로로 표시한다. 나머지 19곳은 대표 위치와 구역을 안내한다. 임의 거리, 시간, 연결선은 수록하지 않았다.
- 사진 22장은 장소별 자료의 콘텐츠 ID, 라이선스, 원본 및 표시 파일의 해시를 기록했다. 제3유형은 전체 비율과 원본 파일을 유지했다. 기존 사진 저장소에 정확히 같은 JPEG가 있는 경우에는 그 공개 URL을 활용한다.
- `batch.json`에는 등록 항목, 동반 원문, 사진 권리와 보행로 근거, 대표 보류 사유를 담았다. 산정호수는 중복, 월성과 서우봉은 접근 위치, 송정박상진호수와 재인폭포는 통제·공사 구역을 다시 확인해야 해 제외했다.
- 데이터베이스에 새 코스만 추가한다. 기존 사용자 데이터와 화면 구성은 보존한다. 기존 테스트와 `node --test tests/municipal-walks-20261113.cjs`로 출처, 사진, 검색, 상세, 사이트맵 연결을 확인한다.
