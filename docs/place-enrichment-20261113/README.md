# 신규 동반장소 383곳 사진·조건 후속 검증

2026년 11월 13일, 직전 묶음의 사진 없는 380곳을 대상으로 기존 한국관광공사 관광 목록과 장소별 이미지를 대조했다. Wikimedia Commons에서 지명과 상호를 구별할 수 있는 354곳도 검색했다. 같은 장소임을 확인한 사진은 동두천 멜팅 3장, 거제 디스커버리카페 2장이다. 한국관광공사 이미지별 공공누리 제3유형 표기를 확인했으며 JPEG 원본과 전체 비율을 보존했다. 사진별 원문 주소·권리 표기·해시를 [검증 기록](verification.json)에 기록했다.

고캠핑 개별 상세 150곳을 다시 읽었고, 이 중 운영사 주소가 연결된 곳은 84곳이었다. 연결된 공개 사이트와 예약·이용 규정을 대조해 14곳의 상세 조건을 보강했다. 멜팅 13kg 이하 및 대형견 제외, 테라피크닉 10kg 이하 중소형견 및 맹견 제외, 남해에코촌 7kg 이하 및 야외 사이트만 동반 가능 등이 포함된다. 사진에 보이는 구역의 출입을 사진만으로 판단하지 않았다.

고캠핑의 현행 운영 항목에 휴업으로 표시된 5곳, 동반 가능 자료와 운영사 규정이 상충한 3곳, 운영사 안내로 동반 객실을 확인할 수 없는 글램핑장 1곳을 공개 보류했다. 데이터는 보존하며 공개 승인 상태만 변경했다. 모의 실행과 실제 변경 후 승인 4,149곳, 이 묶음의 보류 9곳 및 행 수준 보안 활성 상태를 확인했다. 전문업소를 포함한 공개 반려생활 장소 합계는 21,846곳이다.
