# 전체 장소 사진·조건 점검 — 2026-10-19 (3차)

승인 장소 3,133곳 전체를 사진·동반 조건 보유 여부로 분류했다. 현재 사진 보유 1,216곳, 사진 미보유 1,917곳이다. 국문 관광자료 49,601건과 영문 관광자료 15,394건을 대조했고, 기존 사진 출처 1,292개 콘텐츠의 개별 이미지 목록도 조회했다. 영문 근접 후보 173개 중 다른 매장·시설을 제외했으며 동일 장소 5곳은 공개 상세가 제공되지 않아 새 사진을 연결하지 않았다.

사진 33장을 추가했다. 개별 이용 유형 Type1/Type3이 확인된 새 원본 20개(5,550,564바이트)와, 동일 장소로 확인된 기존 산책코스 사진 13개를 연결했다. 서울숲·대운산 등 일부 장소는 새 공식 사진 후보와 중복되어 공용 코스 사진을 추가하지 않았다. 재사용한 코스 사진은 저작자·원문·원본·촬영일·변경 사항·CC BY-SA 또는 공공누리 제1유형 이용 조건을 유지하고 파일을 복제하지 않았다.

개별 이미지 목록에서 Type2/Type4가 확인된 기존 사진 연결 94개(38곳)는 노출에서 제외했다. 이미지 리소스 ID와 해시로 대조했고, 같은 파일이 다른 장소에도 연결된 경우 함께 제외했다. 대표 사진이 제외되면 사용 가능한 추가 사진을 대표로 올렸다. 홈에 있던 제한 사진 1개도 해당 장소의 다른 기존 사진으로 교체했다. 추가 저장 경로에 남아 있던 미사용 제한 사진 2개는 Pages 배포에서 제거했다. 기존 R2 파일 자체는 삭제하지 않았으며 새 키나 권한을 발급하지 않았다. 로그인돼 있던 Cloudflare 편집기에서 기존 사진 제공 Worker에 제한 경로 91개의 차단 규칙만 배포했다(버전 08ba3c99). 91개 모두 HEAD 404, 정상 사진 표본 2개는 200 응답을 확인했고 차단 요청은 R2를 읽지 않는다는 검사도 통과했다.

확인된 Type2/Type4 사진은 향후 잘못 등록되더라도 화면에서 사용하지 않도록 방어 검사를 추가했다. 현재 개별 Type1/Type3 확인 사진 연결은 2,399개, 기존 공개 이용 조건이 확인된 코스 사진 연결은 13개다. 나머지 1,529개는 사진별 유형이 현재 목록에서 재확인되지 않아 기존 국문 관광정보 개방자료의 이용 조건을 근거로 유지했다. 이 숫자를 개별 사진 유형 확인 완료로 집계하지 않았다. 기존 전체 사진 연결은 4,002개에서 제한 사진 제외·신규 사진 추가 후 3,941개다.

확인된 개별 제한 유형은 일반 데이터셋 안내보다 우선 적용했다. 새 사진은 원본 바이트와 전체 비율을 유지했다. 32개 새 원본 후보를 시각 검토하고 사람·주차장·소화전·동물만 크게 보이는 컷 등 부적합 후보를 제외했다. 중복 해시는 하나의 사진으로만 연결했다.

coverage.json은 전체 업종별 보유율과 세부 조건의 미확인 수다. coverage.json.gz와 remaining-places.csv.gz는 전체 공개 장소의 사진·조건 검토 상태 및 다음 조사 분류다. 조회된 공식 자료만으로 모든 장소의 체중·견종·실내 출입 조건을 확정할 수 없으며 기본 동반 표기를 세부 조건 확인으로 바꾸지 않았다.

rights-catalogue.json.gz는 1,292개 콘텐츠 이미지 목록의 출처·리소스 ID·개별 유형·설명이며 removed.json.gz는 제외 근거다. shared-photos.json.gz는 동일 장소의 기존 코스 사진 연결 근거다. selected.json.gz·new-files.json은 추가 사진의 출처·라이선스·해시·크기를 담는다.

자동 SEO 검사에서 기존 홈 카드에 네이버 장소 번호가 없는 경우 검색 링크를 사용하는 정상 동작을 검사 코드가 처리하지 못하던 오류도 수정했다. 특정 장소 링크가 있으면 보존 여부를, 없으면 올바른 장소명의 네이버 검색 링크인지 확인한다.

별도 동반 상세 캐시가 없던 85개 콘텐츠를 추가 조회했지만 모두 상세 조건이 비어 있어 새 조건으로 채우지 않았다. per-image 유형 미확인과 장소별 동반 조건 미확인을 구분해 남겼다.
