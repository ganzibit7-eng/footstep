# 쿠팡 제휴 클릭 집계 · 2026-10-09

관리자 바로가기의 **쿠팡 클릭** 또는 **쿠팡 링크 클릭 · 상품별 · 방문자별 · CSV**에서 확인한다. 기본 기간은 한국 시간 오늘. 최대 90일 날짜 범위, 상품 링크·회원 여부·제외 기록 필터, 클릭 50건/방문자 20개 단위 페이지, 최대 5,000건 CSV를 제공한다. CSV는 첫 조회 시점까지의 고정 범위를 내보내며 수식으로 해석될 수 있는 값은 보호한다.

## 수집과 해석

- 실제 사용자가 누른 주 클릭·키보드 활성화·가운데 버튼 클릭만 수집한다. 렌더링·관리자 표시는 쿠팡 링크를 자동 실행하지 않는다. 쿠팡이 발급한 URL과 sponsored/nofollow/noopener/noreferrer 속성을 유지하며 클릭 이동을 지연시키지 않는다.
- 같은 상품의 700ms 이내 중복 제스처를 억제한다. UUID로 서버 재전송 중복을 방지한다. 방문자별 분당 10건/일 240건 상한이 있다.
- 클릭 시각은 서버가 생성한다. 회원 계정은 auth.uid()로 검증하고 클라이언트의 계정 주장 값은 사용하지 않는다. 등록된 상품과 발급 링크의 정확한 조합만 허용한다.
- 브라우저·기기는 요청 헤더로 종류만 분류한다. 원본 IP·User-Agent·이메일·페이지 쿼리는 클릭 원본에 저장하지 않는다. 쿠팡 URL 자체에도 임의 추적 파라미터를 추가하지 않는다.
- 기존 익명 브라우저 ID를 재사용한다. 관리자 화면에서는 SHA-256 기반 익명 표시 번호를 사용한다. 익명 번호로 실제 신원을 알 수 없다. 회원 목록은 계정별로 묶어 여러 브라우저에서 클릭한 상품을 보여준다.
- 방문자 수는 고유 브라우저 수이며 실제 인원과 다를 수 있다. 로그인 회원과 비로그인 브라우저는 같은 사람이 중복될 수 있어 두 숫자의 합은 총 방문자 수가 아니다.
- 관리자·작업 브라우저는 수집에서 제외한다. 서버가 식별한 자동 접속 신호는 기본 집계에서 제외하고 선택 시 볼 수 있다. 브라우저 보고이므로 조작된 요청/우회한 자동 접속을 완전히 식별하지는 못한다.
- 과거 수집 자료에 상품 식별자가 없어 기능 시작 전 상품별 클릭을 복원하지 않는다. 시작 시각을 관리자에 표시한다. 발자국이 수신한 클릭이며 네트워크 오류·추적 차단·컨텍스트 메뉴의 새 탭 열기는 누락될 수 있다. 쿠팡 공식 클릭·구매·수익 자료가 아니다.

## 권한·보관

private 테이블은 RLS 관리자 SELECT 전용이며 직접 INSERT/UPDATE/DELETE를 클라이언트에 허용하지 않는다. 제한된 기록 RPC만 공개하고 관리자 요약 RPC는 인증+관리자 여부를 서버에서 확인한다. 계정이 바뀐 뒤 늦게 도착한 응답·CSV를 표시하지 않으며 로그아웃 때 화면 데이터를 비운다.
클릭 원본은 90일 기준으로 매일 자동 정리하며 계정에 연결된 클릭은 auth.users 삭제 시 외래 키로 함께 삭제한다. 계정 삭제 작업 중 새 클릭 기록을 차단한다. 비로그인 클릭은 계정에 연결되지 않아 계정 삭제만으로 삭제되지 않는다. 개인정보처리방침에도 이 수집과 보관 범위를 반영했다.

## 검증

실제 DB 롤백 테스트로 UUID 중복, 알려지지 않은 링크 거절, 임의 회원 ID 주장 무시, 일반 회원/비로그인 관리자 조회 거절, 직접 INSERT 거절, RLS 읽기 차단, 회원 여러 브라우저 묶기, 상품·회원 필터, 자동 접속 제외, 페이지 경계, 한국 시간 자정 경계, 테스트 계정 삭제 연쇄 정리를 확인했다. 테스트 계정·클릭은 모두 롤백하여 운영 통계에 남지 않는다.
프런트엔드 검증은 주/가운데 클릭, 가짜 클릭 제외, 작업/자동 접속 제외, 중복 제스처, 쿼리 제거, 계정 전환 중 응답, HTML 삽입 방어와 CSV 수식 방어를 포함한다. 기존 방문 집계·쇼핑·회원탈퇴·로그인 검증도 통과했다.
