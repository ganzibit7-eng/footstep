# 공개 이용 가능한 실제 장소 사진 추가 — 2026-10-19

포천아트밸리, 스타필드 코엑스몰, 휘닉스 스노우파크, 신불산억새평원에 실제 장소 사진 9장(대표 4장·추가 5장)을 연결했다. 사진 보유 장소는 1,216곳에서 1,220곳, 전체 연결 사진은 3,950장이다. 원본 파일 9개(4,604,212바이트)는 제공된 축소본 전체 비율 그대로 저장했다. 새 장소를 등록한 작업은 아니며, 이미 승인된 장소 1곳의 사진 증거 레코드만 새로 작성했다.

공개 사진 검색 23건을 확인하고 13개 파일을 검수했다. 다른 지점·인접 관광지·세부 위치가 맞지 않는 사진은 연결하지 않았다. 재약산 검색 결과의 얼음골 사진은 대상 구역과 맞지 않고 좌표도 유효하지 않아 채택하지 않았다. 코엑스몰 특정 매장, 흐린 과거 사진, 신불산 바위 능선·인물 중심 사진은 제외했다. 신불산 사진은 실제 억새 능선 경관이며 산책 동선의 검증 자료로 사용하지 않았다.

사진별 Commons 원문, 파일 페이지 식별자·리비전, 원본 URL, 제공 축소본 URL, 촬영자·촬영 정보, CC BY/CC BY-SA/CC0 유형과 이용 조건 링크를 기록했다. 사진 원문에 별도 제한 표기가 없는지 확인했고, 제공 파일 해시·형식·크기를 검증했다. 촬영 시점은 2008~2025년으로 다양하므로 현재 시설·운영 상태를 보장하는 사진으로 표기하지 않았다.

출처·이용 조건은 사진마다 보존하고 사진 제목·저작자·라이선스명·링크·변경 사항을 함께 표시한다. 기존 산책코스 사진 13개의 제목도 같은 방식으로 보완했다. 사진을 새로 합성하거나 임의로 자르지 않았으며 기존 로그인·GPS·회원 데이터는 변경하지 않았다.

개별 사진의 이용 조건은 selected.json.gz의 Commons 원문 및 메타데이터를 따른다. commons-candidates.json.gz는 후보·배제 검토에 사용한 공식 공개 API 응답이며 new-files.json은 배포 파일 무결성 목록이다.

국문 관광자료 49,601건·영문 자료 15,394건 대조, 사진 출처 1,292개 콘텐츠의 개별 유형 조회, 별도 동반 상세 조회가 없던 85곳의 추가 확인까지 함께 진행했다. 85곳은 상세 동반 정보가 비어 있어 조건을 만들지 않았다. 3,133곳 전체의 사진·조건 상태는 coverage.json과 coverage.json.gz, remaining-places.csv.gz에 정리했다. 사진이 없는 곳과 세부 조건이 없는 곳을 완료로 집계하지 않았다.

이전 단계에서 확인한 상업적 이용 제한 사진 연결 94개는 계속 제외하며, 사진 서버의 해당 직접 경로 91개 차단도 유지한다. 관련 근거와 Worker 배포 검증은 docs/place-enrichment-20261019c에 보관한다.
