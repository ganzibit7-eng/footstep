# 산책 경로 추가 검토 · 2026-10-09

300개 공개 코스와 비교하여 공식 GPX 후보 18개 중 10개를 추가했다. 양평 물소리길 8개, 동래읍성 장대길 1개, 차탄천 에움길 1개다. 원본의 단일 연결 구간, 한국 내 좌표, 최대 좌표 간격 220m, 안내 거리 대비 70–130%, 공식 시작·종료 좌표와 220m 이내 일치를 확인했다. 50m 간격 표본에서 60m 이내 기존·신규 경로 중복이 30%를 넘는 후보는 보류했다. 원본 좌표를 연결하기 위해 새 좌표를 만들거나 끊긴 구간을 보간하지 않았다.

반려견 동반 조건은 모두 미확인이다. 동반 확인 필요 태그와 상세 안내를 표시하며 홈페이지·몽이 자동 추천에서 제외한다. 난이도는 일반 보행 기준이고 현장 운영·공사·시설 제한은 방문 전에 확인해야 한다. 공식 자료를 확인한 날짜는 현장 방문을 뜻하지 않는다.

GPX와 단순 경로 사실만 저장하고 장문의 관광 소개·두루누비 사진은 복사하지 않았다. 출처: 한국관광공사 두루누비 공식 자료실 / getRouteCourses.do. GPX 외부 활용 참고: https://www.data.go.kr/data/15101974/openapi.do

원본 GPX 10개 및 SHA-256·표시 좌표는 routes.json.gz, 후보 보류 사유는 decisions.json, 등록 데이터는 database_sql/seed_expansion_walks_20261009.sql에 보존한다. 기존 300개 경로 비교본은 baseline-routes.json.gz이다. 사진은 물소리길 1코스 한음 신도비와 3코스 양평 물안개공원 경유지 실제 사진 2장이다. 경기도뉴스포털의 공공누리 제1유형 표시, 사진 캡션과 구간 경유지를 확인했다. 두 사진은 코스 전 구간을 대표하거나 동반 허용을 증명하는 사진으로 설명하지 않는다. 촬영일 미표기·게시일을 구분하고 출처·이용 조건·변환 내역을 표시한다.

사진 출처 페이지의 증거는 photo-source-*.html, 사진 이용 정보는 photo-batch.json이다. 차탄천 사진은 라이선스 확인 후에도 다운로드에 실패하여 추가하지 않았다. 양평 자체 코스 페이지 사진은 개별 이용 조건이 명확하지 않아 사용하지 않았다.

검증: node tests/expansion-20261009.cjs, node tests/course-photo-integrity.cjs. SQL은 새 ID만 추가하고 기존 또는 사용자 소유 행과 충돌하면 트랜잭션을 중단한다.
