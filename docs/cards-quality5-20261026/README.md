# 5차 카드·상세 UI 품질 개선

기준 main: b7fa9462e8. 2026-10-26. 구현·로컬 검증·main push·운영 배포 확인 완료.

## 실제 수정

- 추천 카드의 첫 링크나 페이지 전체에서 사진을 다시 찾던 구조를 제거했다. 정규 상세 주소와 같은 장소 레코드의 사진·조건·이름으로만 카드를 생성한다. 사진 없는 페이지가 다른 추천 장소의 사진을 빌려오던 경로를 차단했다.
- `scripts/place-card.mjs`는 정적 목록과 함께 보기의 단일 카드 생성기다. 프레임 → 지역·종류 → 이름 → 주소/짧은 소개 → 핵심 정보 → 출처 → CTA의 7단 구조를 사용한다.
- `card-media.js/css`는 사용 조건에 따른 cover/contain, 중립 배경, 사진 없음 표시, 출처 접기와 48px CTA를 공유한다. noCrop·변경금지·불명확한 라이선스·작은 이미지는 전체 비율을 유지한다. 허용된 사진만 미세 확대한다.
- 카드의 사진·제목 시작 위치와 같은 행 CTA 기준선을 맞췄다. 1열 모바일, 2·3열 목록, 긴 이름과 미확인 조건을 처리한다. 출처 전문과 원문은 보존한다.
- 동적 검색, 전문업소 목록, 홈 외 산책코스와 프로필 코스, 찜한 장소 표시도 정리했다. 저장 데이터에는 이름/ID만 있어 사진이나 조건을 추측하지 않고 ‘사진은 상세에서 확인’으로 안내한다. 저장 방식은 그대로다. 공개 업소명이 `-`인 경우 원천 기록을 바꾸지 않고 목록에서 ‘업소명 미확인’으로 표시한다.
- 홈 추천 카드·사진·레이아웃·강아지와 지도/GPS/로그인/DB는 유지한다. 숨김 업데이트 내역에만 같은 날짜의 짧은 주제를 더했다. 홈 공지창은 복구하지 않았다.
- 정적 상세/목록은 새 카드 스크립트 없이 표시한다. 동적 검색/전문업소 화면에서만 필요한 순서로 불러오며, 새 라이브러리·DB 요청을 추가하지 않았다.
