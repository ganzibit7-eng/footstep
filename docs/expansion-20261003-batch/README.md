# 전국 코스·동반 장소 확장 · 2026-10-03

전국 한국관광공사 후보 524건의 개별 반려동물 조건과 공개 상태를 확인했다. 신규 장소 301건, 기존 안내 갱신 3건, 공식 GPX 코스 12건을 추가한다. 현장 답사나 오늘 영업 인증이 아닌 공개 자료 확인이다.

`place-decisions.json`과 `route-decisions.json`은 불가·불명확 구역·동명 지역·기존 경로 겹침·좌표 및 거리 불일치 등의 제외 이유를 기록한다. 일부구역 장소는 해당 구역이나 이용 조건을 특정할 수 있을 때만 반영한다. 국립화천숲속야영장과 순천자연휴양림 등은 운영자 조건 재확인이 필요해 보류했다. 영남알프스 후보는 신불산 자연휴양림의 동반 불가와 경로 범위를 확정할 수 없어 보류했다.

공식 목록: https://korean.visitkorea.or.kr/other/other_list.do?otdid=22dd6a3f-9d71-42f8-9163-295a7ac62fb8
개별 조건은 해당 공개 상세 페이지의 `FETCH_CONTENT_DETAIL_INFO(fieldType=10)`와 `TOUR_CONTENT_BODY_DETAIL`에서 확인했다. GPX는 https://www.durunubi.kr/ 의 공개 코스 원본 다운로드를 사용했다. 사진을 확보하지 않은 신규 코스에는 기존의 이미지 없는 코스 안내를 유지한다.

기존 공공데이터 주소 1266건을 설명에서 주소 필드로 복원한다. 이름·위치·분류·설명이 모두 같은 중복 45건은 삭제하지 않고 `duplicate` 상태로 보존하며 최초 공개 ID로 연결한다. `before-imported-places.json.gz`에 변경 전 공공데이터를 보존했다. 사용자 소유 항목은 수정하지 않았다.

지도 분류·이름 및 주소 검색, 공식 안내 링크, 정적 지역·분류 목록과 사이트맵을 확장한다. CSV 미리보기는 HTML을 이스케이프하고 일괄 등록의 중복·비정상 좌표를 제외한다. 분석 테스트 제외 설정을 유지한다.
