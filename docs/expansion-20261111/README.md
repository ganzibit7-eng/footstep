# 반려견 동반장소와 산책코스 확대 · 2026-11-11

식품안전나라의 반려동물 동반 출입 음식점 2,907개 원자료를 소상공인시장진흥공단의 2026년 9월 30일 상가 자료와 대조했다. 상호 또는 지점명, 시군구, 도로명과 건물번호가 유일하게 맞고 국내 좌표가 있는 자료만 사용했다. 기존 공개·보류 자료와도 대조했다. 식약처 명단은 11월 11일 조회했고 견종·체중·허용 구역의 세부 조건은 표시된 공식 정보에 따라 확인 필요로 안내한다.

최종 묶음은 신규 동반장소 940곳과 신규 산책코스 3개다. 동반장소에는 음식점·카페·제과점 938곳, 김유정역 폐역과 나정고운모래해변 2곳이 포함된다. 음식점 등 22곳, 관광지 2곳, 코스 3개에 개별 재사용 조건을 확인한 실제 사진을 연결했다. 나머지 음식점 후보 중 239곳은 기존 배포 용량 기준 안에서 한 묶음으로 반영하기 위해 보류했다. 두 곳은 공식 자료의 동반 안내가 달라 별도로 보류했다. 사진 자료는 원본 JPEG 바이트와 전체 비율을 유지한다.

안중근공원 0.21km, 봉화산 2.54km, 안양예술공원 0.22km의 경계 안에서 OpenStreetMap의 인접 보행로 노드만 연결했다. 세 코스 모두 지도 기반 제안 경로다. 기존 경로의 25m 주변과 10% 이상 겹치는 경로를 제외했다. 사진은 해당 장소 경관을 보여준다. 출입구, 난이도, 현재 통제와 실내·수경·놀이시설 동반 여부는 별도로 확인해야 한다.

`batch.json`에는 신규 공개 행을, `source-proof.json`에는 상호·주소·좌표 대조 및 사진별 원본 권리와 해시를, `route-proof.json`에는 사용한 OSM 원본 노드·웨이·경계를 보관한다. 신규 공개 수는 코스 415개, 동반장소 4,221곳이다. 전문업소 17,698곳과 중복 1곳을 반영한 반려생활 장소 합계는 21,918곳이다.

등록 모의 실행에서 기존 데이터와의 충돌 0건을 확인했다. 실제 등록 후 승인 코스 415개와 동반장소 4,221곳을 대조했고, 두 테이블의 행 수준 접근 제어는 계속 활성화되어 있다. 로컬 저장소 회귀 검사 432개를 통과했다. 공개 원본 크기는 973,997,575바이트로 975MB 기준 이하다. 브라우저에서 봉화산 상세의 사진·제안 경로 안내와 조양방직 검색·상세·출처를 확인했다.
